# 发行安装说明要求

每次发行说明必须包含部署教程、一键安装包、SHA256和下面可复制给 AI Agent 的一句话：

> 请使用本轮v3.5.0一键安装包中的部署教程，将全部19项通用学术Skill安装到本机Codex，核验安装包SHA256、备份同名旧版，并在安装后报告实际路径、版本和检查结果。

后续发行替换为本次实际版本和发行链接，同步更新安装器固定版本及校验值，重新检查安装、备份、恢复和异常回滚；不得沿用旧校验值。注明操作系统和 Python 要求，区分文件检查与宿主实际加载。当前一键包验收范围为macOS ARM64及已有Codex系统安装器；Linux仅工程CLI有CI，Windows和其他宿主安装未验证。核对所有下载链接并保留历史发行资产。

同版本的发布后文档更正同步维护源与生成参考，发行页注明独立文档提交、补充文件及SHA256；原程序包、标签和历史验收收据继续按各自原身份引用，不静默覆盖。更新安装导航、更新日志、迁移、架构与兼容性说明，并实际核对链接及生成一致性。
