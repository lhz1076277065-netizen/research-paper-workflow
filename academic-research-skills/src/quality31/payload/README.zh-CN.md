# Academic Research Skills · v3.5.0

1个总控与18个独立专业Skill，从同一维护源码生成。完整研究以“真实缺口 → 既有局限或竞争解释 → 本文贡献及判别证据 → 新认知、意义与边界”贯穿选题、设计、实验、图表、写作与复核。主线随结果修订，不能先定结论再挑数据；它是本Skill的论证框架，不是所有顶刊统一的官方录用公式。

每个专业步骤仍必须调用指定14库内匹配的真实入口；开放选题默认Orchestra，固定问题使用Scholar问题卡。读取并实施来源流程，finish/check核对当前输入和产物后才移交；缺匹配入口报障，禁止host_fallback。23个真实入口及原生限制保留，完整研究把当前路线板作为后续调用输入；每篇无需调用不相关仓库。
