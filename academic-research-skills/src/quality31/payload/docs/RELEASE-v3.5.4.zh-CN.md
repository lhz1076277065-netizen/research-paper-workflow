# v3.5.4：必要数据本地齐备后完成实验、图稿与润色

完整实证研究默认按[本地数据全流程](local-data-workflow.md)执行。研究设计形成执行版计划，评估全部必要数据，联网比较权威来源，完整获取计划需要的内容并核验，之后本机准备/试跑、正式实验与复算、科研绘图、论文审查、表达润色及事实核对。官方子集满足研究需要时无需下载整个数据池。

新增local_data.py将真实设计输出、数据清单、来源选择收据和本地文件绑定到当前阶段。缺文件、解析失败或前序工作缺失时给出修复动作，保持自主解阻；不会把网址、已下载状态或文件数量当作完成。摘要分块计算，普通检查可复用未变文件的已读缓存，阶段出口及正式实验启动重新完整核验。

继续保留14库必调、同研究200 GB累计下载及项目占用限制、真实用户预算、自定计划可重排、内容绑定的审查复用和精简恢复。局部任务及历史记录保持其真实范围；19个独立Skill由维护源码同步生成。入口只路由，详细步骤按需读取。
