# v3.5.6：研究变更后的精确失效与可靠续接

本版修复语言要求变化后旧稿/旧审查仍被复用、科学目标变化后恢复指向旧工作与旧路线，以及方法修改后旧步骤仍可登记完成的问题。

- 启动、完成、审查复用、阶段出口和交付统一核对当前科学身份、适用实验版本及表达要求。历史收据继续保留文件和来源核验用途。
- `professional_flow.py begin` 新增可重复的 `--experiment-id`；Python API对应可选`experiment_ids`。同一问题下的方法修改只影响相关实验，未变结果和数据准备可继续复用。完整设计和整稿写作仍包含全部主要实验。
- 科学目标变更保留历史，取消被替代的未消费专业步骤，更新当前指令及复评下一动作；旧路线不能用于关闭新目标。原预算、容量、计量和暂停边界保留。
- 一次恢复仅验证一次研究约定，共用实验索引并去重文件摘要；写作和交付继续核验完整内容与来源。

本版保留19项独立Skill、14库匹配入口必调、自主解阻及200 GB累计下载/项目占用边界。安装不自动恢复其他研究会话。
