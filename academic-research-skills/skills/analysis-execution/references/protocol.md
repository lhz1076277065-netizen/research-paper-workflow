# 实际研究执行协议

> 按任务查阅本参考的相关部分，灵活组合步骤；它不是逐项审批流程。具体输出以用户目标为准。


## 执行前检查

读取数字完成路径、问题与决定性检验，核数据、形式对象或可执行项目、软件/权限及适用报告规范。动态检查系统、架构、内存/磁盘、运行时、编译器、CPU线程和实际加速后端，个人设备信息留当前项目。区分自己实际观察的状态和上游声称完成的状态。缺失方案时可从材料重建合理方案，但保留已接触结果的事实，不能追认预设。

## 建立可复现执行记录

记录系统、运行环境、依赖/锁文件、软件版本、数据哈希、代码提交或文件哈希、参数、随机种子、硬件与数值容差（适用时）。日志保留命令、输入、输出、耗时、退出状态、警告和失败。代表任务实测耗时、内存和数值行为；按问题选CPU或适用GPU/Metal/MPS等，版本/算子/精度按当前官方资料与实跑确认。分解、向量化、稀疏、并行、编译、缓存、内存映射、流式/分块与恢复用于有效正式规模；性能比较保持同等科学条件。

## 正式研究

用当前Agent作为executor执行真实计算、求解、推导或数字资料解释，research_model作为研究对象/算法单列权重、许可、框架、训练与评价。已安装API/CLI/脚本优先，免费缺依赖在实际项目环境准备并验证；R、Julia、C/C++、Rust、GIS、CAD和仿真器选真实实现，不强制Python。需要GUI时实际配置、运行、读日志、提取和校验专业量，保存可编辑项目与正式输出。适用时先描述样本与数据质量，再基线/对照，最后主要模型与扩展。结果不可由语言模型凭模式猜测；任何数值、表或运行成功都必须有实际输出。

原主题需要新增人工或实体操作时，优先已有合法数字记录、计算模型或理论完成的贡献，并明确转化后问题。计算设计与分子/材料候选限于已完成数值/算法证据，不能声称物理验证；外部事项单列，继续独立工作。

## 方法特异执行

回归/层级：合适结果分布、依赖、诊断、效应与区间。因果：设计特异诊断、识别假设与敏感性。预测：严格训练验证流程、锁定测试集、基线与校准。SEM：测量和结构诊断、识别、估计与不变性。仿真：实现正确性、数值收敛与模型适用性分别检查，保留参数、重复和Monte Carlo误差。定性：可追溯编码与反例。综述：筛选、提取、偏倚与适用综合。理论：数值线索、猜想、已证命题分层，记录定义、证明依赖、条件与边界构造。

细节依据本地 method-routing 与核实方法来源，不必把所有模型都跑一遍。

## 数值与解释

每个主要结果用稳定result_id关联问题、分析性质、原始值/显示精度、单位、总体/独立样本、结局、比较、模型/分区、时间、区间、源文件定位与数据/代码/执行版本。理论关联命题/条件/证明位置版本，解释关联材料定位、支持片段与推断。区分相对改善与绝对差、百分比与百分点、标准差与标准误、样本与观察数。

保存未舍入输出，稿件显示值从同一来源按规则生成。没有不确定性估计时记录原因和不能支撑的主张，不能编造置信区间。

## 偏离、失败与冻结

将执行变为 discovery loop：实际检验 → 数据/实现/评价诊断 → 仍然存在的科学异常或能力瓶颈 → 可反驳的新假设、算法、命题或设计 → 在开发材料上实施新检验 → 更新贡献与近邻。先修工程错误，避免从错误实现创造“理论”；真实异常保留相容解释，明确什么结果能区分。每轮保存关键观察、改变部分、实际输出与判断变化，沿用研究笔记而非新建逐步审批表。

反例可触发修正条件、构造更紧界或新证明；方法失败可触发新表示、目标、求解策略或测量设计。新路线不是口头建议：在当前授权与资源内完成信息价值最高的下一项推导、构造或计算。探索结果不能再次冒充独立验证；验证信息已暴露就披露并取得新检验，不能反复调到留出结果好看。只有已知原理或弱基线优势时按[贡献升级](research-quality.md)返回研究；重要零结果与边界是否成立由其改变的认识判断。

模型不收敛、质量不足、测量无效或基线更好均是需要报告的结果。合理修复须有变更原因，保留前后版本；不能只保存最好的随机种子。初始方法不佳或意外结果先定位材料、实现与评价，再改估计器、表示、目标、算法、资源利用、证明条件或数字设计；对照最近邻检验新部分，或发展重要适用边界。下一轮优先减少关键不确定性，开发不触碰正式留出评价。

冻结可供下游使用的结果清单与全部必要输出。待进一步检验的结果明确 provisional；冻结只是版本稳定，不表示结论永远正确。
