# 从研究问题到可验证数据下载

本协议的专业步骤服从[阶段出口与预算](phase-control.md)：维护/局部请求保持范围；昂贵动作先核主张与成本；两次不同修复或两轮无信息增量必须复评；无可行检验就交付报告。恢复不重置预算或重复完成事项。


> 按任务查阅本参考的相关部分，灵活组合步骤；它不是逐项审批流程。具体输出以用户目标为准。


## 数据需求规格

列出必需与可选变量、概念对应、对象、独立单位、时间和空间覆盖、分辨率、样本信息量、更新频率、标签/结局、潜在连接键和验证集需求。先问能否回答研究问题，再问哪个数据集容易下载。

## 查找与候选比较

按最近邻论文数据声明/附件→作者数据与代码仓储→权威领域来源→通用公开仓储主动搜索。候选可用OpenML、UCI、Hugging Face Datasets、Zenodo、OSF、Figshare、Dryad及政府/机构门户，具体入口按问题选择。平台名称不是质量保证。记录搜索式、候选来源、持久标识、版本与镜像关系。

先取得元数据、字典及代表记录，核对对象、概念/变量定义、结局/标签、测量时间、尺度、分组/独立单位、缺失重复及原研究用法。按真实内容判断匹配、覆盖、测量、格式、成本和许可，必要时回到问题或方法调整。仅换数据集名称不能视为完成匹配。同一数据多个镜像不算独立验证集。

## 获取前核验

分别核对公开元数据、免费访问和研究再使用许可；仓储也可有受限文件，平台名称不替代单项许可。优先免费、许可清楚、当前可自动取得的资源；已有合法账号继续用，其他访问事项单列并推进可取得替代。检查存储、下载量、API 限流、分页与授权范围。巨大下载先确认资源条件，允许按问题选择合法子集，但记录范围且不为得到期望结果选择子集。

## 实际获取

匹配检查后用当前可用且授权的API、CLI、脚本或浏览器取得正式材料。记录请求端点与非秘密参数、筛选、分页、返回码、重试、开始结束、版本/ETag（有时）、期望与实际文件数/大小。处理超时、失败、断点续传与重复，不把“有下载链接”标记为已下载。

检查内容类型、压缩包安全、文件可解析性、页数/记录数和是否误下载登录页或错误 HTML。解压防路径穿越与恶意内容；陌生代码先检查，不能因为附在数据集里就执行。

## 原始数据封存

保存只读原始文件与 SHA-256，使用数据供应者校验值时注明算法。保留原始 API 响应或可再获取凭据以外的查询参数，以及下载日志、来源、许可和数据字典。文件完整性不等于数据无偏或测量正确。

区分来源数据的发布版本、覆盖截止、下载日期与本研究冻结版本。最新数据不一定适合历史复现或时间外验证；选择某版本须有研究理由，而不是一律替换到最新。

## 无法取得时

保留候选元数据和真实阻塞：访问待批、变量不存在、数据已撤下、许可证冲突或格式不可用。提出合法替代与主张收窄，不绕过权限、不伪造数据、不把替代数据冒称原数据。

交付实际材料、下载/校验、字典、许可、版本与查询及匹配判断，进入正式准备和分析；候选与未取得项分开。跨来源验证按真实独立观察来源，镜像或同队列合并标记；综述从原文/附件取得实际综合统计量、定义和条件，处理重复报告与依赖。工具机制按需读[计算研究路线](computational-routes.md)。
