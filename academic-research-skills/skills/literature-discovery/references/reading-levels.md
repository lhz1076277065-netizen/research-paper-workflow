# 阅读层级与来源定位

每篇论文分别记录每种材料的访问状态，不使用一个“已读”覆盖全部内容。

- metadata_only：只取得题名、作者、DOI、年份等。
- abstract_read：直接阅读摘要，不等同于模型与结果完全核验。
- full_text_read：阅读正文中记录的章节，仍需注明跳过内容。
- figures_visually_inspected：实际打开并查看所列图与面板。
- tables_inspected：检查表头、单位、行列、脚注与数值。
- supplement_read：阅读实际取得的补充材料。
- code_inspected：打开代码并定位有关实现，但没有因此默认运行过。
- code_executed：真实执行代码，有环境、命令、输入和输出日志。

这些不是必须逐项同时满足的排名。一个论文可能全文不可得但图表在合法网页可读；也可能全文已读但代码缺失。每一项分别用 observed / unavailable / not_attempted / not_applicable，附 locator、时间和证据。

PDF 优先提取文本以查找章节；涉及图、表、公式版式时实际渲染相应页面并视觉检查。能使用平台 PDF 截图功能时使用；本地文件使用实际 PDF 渲染器。分别记录 PDF 页索引与印刷页码，以免错位。不以 OCR 猜测作为唯一关键证据；OCR 仅在缺少文本层且无法可靠直接阅读时作为辅助。

HTML 查看实际图像及 caption，而不只读取图片 alt 文本。绘图软件必须根据 Methods、caption、代码或作者说明核实；外观只能支持“可能的重绘实现建议”，不能支持“作者用了某软件”。

付费或权限不足时保留 DOI、摘要与访问失败状态，寻找合法作者存档或用户授权全文。不能绕过权限。关键图和模型仍未读取时，精读结论为 provisional，不宣称完成了全文对标。
