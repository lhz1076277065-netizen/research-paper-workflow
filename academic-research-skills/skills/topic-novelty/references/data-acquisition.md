# 自主访问与有界资料获取

## 先规划本次研究真正需要的资料

在首次获取前把计划写入现有研究笔记：支持的主张/检验，变量、对象、时间、地域、分辨率、文件或模型版本；可用访问渠道；预计下载、压缩包、解压、衍生数据、模型缓存、临时计算与导出的空间，以及这些文件同时存在时的峰值。先查元数据和小样本校准估算；未知大小写范围，取保守上界并做有界探测，不能以“未知”开始无限下载。已经有的数据也计入项目空间。

每个研究默认硬上限为 **200 GB = 200,000,000,000 bytes**：累计接收的数据字节与当前项目文件容量分别不得超过该上限。下载失败、重试、清理、阶段转换与恢复不重置累计数。动作超出原容量估计时，先用实际信息更新计划再执行，额度不因此增加。磁盘另保留默认10 GB空闲；磁盘不足时先改获取/处理方式，不能把200 GB视为应当用满的配额。

优先服务器/API按需子集、范围请求、远程查询或分块流式读取；只下载实际检验所需资料。确实只提供整包时允许下载整包，先计入整包与必要解压成员共存的峰值，并在笔记说明为何不可拆分。解压只取所需成员，不展开整个数据池。不能为省容量破坏代表性、独立单位或承诺的研究尺度。模型权重、工具下载、重复副本和任务缓存同样计入；把HF_HOME等任务专属缓存路径指向项目内，不借全局目录隐藏占用，不修改HOME或CODEX_HOME。

## 常规访问由Agent处理

沿用用户在会话中给出的自主访问授权：常规研究相关登录、免费账号流程、普通免费数据使用条款、API token创建与配置由Agent处理，不重复询问。优先用相关服务已有浏览器登录态、连接器和受支持的凭据来源；只读取该服务必要配置。凭据保存在该服务合适的密钥存储/受保护配置；脚本通过环境变量名取值，不放命令参数、笔记、源码、输出或交付包。

返回登录HTML、401/403、token失效或下载门户跳转时，先核对官方访问流程并实际修复登录、条款或配置；未成功则比较并执行官方镜像、等价公开材料、已有合法缓存等适配原问题的路径。渠道失效只关闭该渠道，继续独立设计、分析和写作。授权记录不是凭据，也不能伪造验证码、MFA或许可；只有确实不可替代且平台无法代办的操作才向用户提出一次具体最小请求，同时推进其余工作。额外费用、特殊协议承诺或改变固定科学问题仍按真实授权处理。

## 实际执行

使用同一项目根目录的research_storage.py收据；不得按阶段、数据集或新目录重新立配额。完整/显式预算任务先把该收据绑定原phase，再运行有界获取。旧项目未计量的历史传输保持未知，扫描已有文件并补当前计划，不宣称历史累计严格达标。小型纯写作无需创建下载计划。

```json
{
  "needs": [{"purpose": "检验核心主张", "subset": "实际所需变量、范围和文件", "access": "已授权官方子集API"}],
  "expected_download_bytes": 1000000,
  "expected_peak_project_bytes": 4000000
}
```

expected_download_bytes是本次计划的未来传输上界，工具加上已发生的累计数；expected_peak_project_bytes是包含已有文件的项目峰值。先据元数据填写真实估计，不照抄示例数字。

```bash
python3 scripts/research_storage.py --root project plan --spec project/acquisition-plan.json
python3 scripts/phase_control.py --state project/phase.json storage --root project
python3 scripts/research_storage.py --root project download --url '官方资料URL' --output raw/input.zip --max-bytes 1000000 --need 0 --phase project/phase.json
# token通过 --token-env RESEARCH_DATA_TOKEN 取值；参数只含变量名。
python3 scripts/research_storage.py --root project extract --archive raw/input.zip --member needed.csv --output derived --phase project/phase.json
python3 scripts/phase_control.py --state project/phase.json guard --estimated-bytes 3000000
```

工具检查实际剩余额度、磁盘余量、远端大小、流式接收和所选成员解压；保留失败的部分文件及接收计数，不覆盖已有材料，拒绝路径逃逸和链接。默认单项目一个受管获取，避免并发抢占额度；查已有作业再续接，不重复启动。批量、浏览器、SDK或云盘工具不能被脚本自动拦截：使用前做同等预检、设置其实际限额/子集，以record --bytes --evidence --need登记不含密钥的实际字节收据，重复收据拒绝计数；外部字节报告不冒充工具独立测量。已发生超限也保留真实计数。无法可靠限额时改用有界实现，不启动无界后台下载。云端处理后本机仅取必要输出，但远端费用与权限仍需真实授权。

配额触发的是重新规划获取：选择有效子集、远端计算、低存储实现、去除重复或清理自己生成且可再生的临时文件后继续；保留原始证据、失败记录与无关文件。累计额度用尽后继续已有材料上的工作，不再下载；必要数据仍缺失则如实报告该缺口。phase run周期监测自己的作业，但不是OS磁盘沙箱；严格逐块限额适用于受管下载/解压，不能声称所有外部工具都受强制拦截。
