# 本项目能力索引

按任务选用，条目不是执行顺序。对应独立目录由宿主读取；不需要先安装其他模块。

| 能力 | 用途 |
|---|---|
| `analysis-execution` | 运行分析、实验、仿真、推导或资料解释，形成可复查的实际结果。 |
| `citation-audit` | 核对引用的身份、语义支持与出版状态，并修复稿件和书目对应。 |
| `data-discovery` | 寻找适合问题的数据或材料，比较来源并实际获取所需内容。 |
| `data-preparation` | 把原始数据或材料整理为可分析版本，核对变量、连接、缺失与分区。 |
| `ethics-protocol` | 处理研究实际涉及的伦理、数据权限、预注册、作者信息与披露。 |
| `journal-intelligence` | 识别领域标杆期刊，或为实际稿件匹配期刊，解释契合点与差距。 |
| `literature-discovery` | 查找文献、筛选摘要并综合证据地图，支持选题、综述和最近邻查找。 |
| `manuscript-review` | 审查论文的科学论证、方法、图表与语言，并落实有依据的修订。 |
| `manuscript-writing` | 撰写、补全或重构学术论文，形成有说服力的论证和完整可编辑稿件。 |
| `paper-deep-reading` | 精读论文的选题、模型、方法和图表，重建证据链并提炼可迁移设计。 |
| `peer-review-response` | 处理审稿意见、实施修订与补充工作，形成逐点回复和对应稿件。 |
| `publication-stewardship` | 核对校样、关联研究版本、准备归档并处理发表后更正。 |
| `research-design` | 围绕问题选择研究设计、方法、验证方案与适用的分析计划。 |
| `research-intake` | 理解研究目标、领域与材料，确定可执行的起点和有价值的下一步。 |
| `research-paper-workflow` | 协调从选题到发表维护的研究；按实际依赖连接独立能力并交付完整成果。 |
| `robustness-reproducibility` | 检验关键结果的敏感性、替代解释与复现，更新可支持的论断。 |
| `scientific-visualization` | 选择表达形式并制作、修改或审查科研图表，核对数值与最终画面。 |
| `submission-packaging` | 按实际目标期刊准备投稿稿件、附件、投稿信与所需声明。 |
| `topic-novelty` | 生成有价值、可检验的研究问题，对照最近邻分析创新与实现路线。 |
