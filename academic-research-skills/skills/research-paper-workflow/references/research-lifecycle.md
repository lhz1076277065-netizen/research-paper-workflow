# 全生命周期：可控的目标、可迭代的研究

只在完整研究中使用；从用户当前阶段进入，复用已有成果。默认`computational-autonomous`，当前Agent作为executor协调，研究模型与专业软件承担相应计算。核心问题要有数字完成路径：关键科学问题 → 所需证据 → 可取得材料或形式对象 → 软件与算法 → 区分主要解释的验证 → 预期贡献。具体路线按需读[计算研究路线](computational-routes.md)。

| 阶段 | 当前Agent实际要完成的判断/工作 | 可复用的专业能力与产物 |
|---|---|---|
| 问题与定位 | 顶刊跨篇学习揭示什么现实问题与科学未知；数据/尺度怎样支持新增认识或行动 | 标杆学习与问题综合、精读、创新核查；简明选题与下一项决定性工作 |
| 研究设计 | 竞争解释分别预测什么；什么数字操作能区分；材料与资源是否适配 | 方法规划、真实材料获取、伦理/方案；研究方案与关键验证 |
| 实际研究 | 校准成本，执行分析/推导/求解；先诊断异常，再改进方法或发展边界 | 数据准备、分析执行、稳健性；真实结果、可编辑项目与研究迭代 |
| 图表论证 | 最重要新增结论与关键例外如何直接判断 | 指定库绘图Skill完成选图—制作—核查；结果关联的主图与编辑源 |
| 稿件与复核 | 核心贡献是否清楚且有证据；完整写作与引用核对 | 专业写作与审查；实际全文、补充、来源 |
| 最终表达 | 用指定anti-defensive-writing整理已成立贡献；复核语义不变 | 原稿/修订稿、实际写作Skill记录与事实复核 |
| 选刊与交付 | 是否符合用户目标和当前期刊要求；有哪些研究缺口 | 最终选刊、交付索引、投稿材料；正式提交需真实授权 |
| 返修与发表维护 | 有真实意见/校样时处理；无此输入就待后续 | 回复审稿、版本更正与归档，不伪造未来工作已完成 |

已有路线板记录目标、六维画像、主张、最近邻增量、决定性证据、实际文件/版本和Skill范围。未给材料主动找；不适配核字典/记录；资源不足改算法/规模；命题直接推导；原理作基线继续发展增量。项目不是19个Skill排队打卡。

## 三个轻量队列

| 队列 | 记录与推进 |
|---|---|
| 研究工作 | 新思路、基线、决定性验证、证明、边界与独立检查；每项留一能减少关键不确定性的动作 |
| 成果工作 | 主图、写作、引用、结果数值、编辑源、渲染与期刊适配；记录真实文件和依赖 |
| 外部事项 | 作者信息、声明、特定访问权限和正式提交；写明影响范围与待确认事项 |

队列用三段笔记即可。等待外部时继续独立研究/成果工作；可推进任务完成后交付当前结果和待确认项。早期核实接受相应数字研究的期刊，终稿按实际贡献/证据匹配。

在三个自然决策点向用户说明：选题/方法有了实质方案时，决定性结果改变原想法时，完整图稿将要交付时。用户已授权自主推进则简短更新并继续；主问题、目标层级、未经同意的外发或额外费用改变需确认。不要每个函数都请求许可。

分别报告科学问题、专业实施/图稿与投稿准备完成度，工程检查单列；另一宿主或旧版对照包不成为研究依赖。预算不足保存高价值进展和下一关键检验，不用琐碎小题冒充完成。


## 续接只保存会改变决策的信息

沿用路线板与三个队列：当前问题、主张/竞争预测、关键证据缺口、专业实现、已完成产物版本及下一项动作。中断后核对真实文件再恢复；摘要只作定位。数据/方法变化更新关联结果与图稿，编辑源变化重建受影响导出；局部图注/排版变化不从头重跑分析。结果、稿件、PDF与外部回执分别报告真实完成层级。
