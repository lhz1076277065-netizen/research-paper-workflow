# 现实问题导向的顶刊学习与选题

用于开放选题、领域探索和重新定位。明确的局部改稿、既定方法执行继续原任务。目标是提出值得回答、能取得证据的问题：现实需要带来研究动机，学术未知构成研究任务，方法服务二者。

## 先读问题，再学作者怎样回答

在实际子领域核实标杆期刊与相关代表作，结合近期研究、关键经典、不同设计和重要相反发现。标杆学习库学习问题与论证；最近邻证据库覆盖直接相关工作；实践材料补充真实决策、服务、资源与环境中的需要。现有领域材料足够时直接深化，新增检索围绕会改变选题判断的缺口。

先读真实摘要筛选，再对决定候选的论文读引言、方法、关键图表及必要附件/代码。原文的选题理由、实际证据与自己的迁移推断分开表达；出版叙事用于理解文章逻辑，不冒充作者真实构思历史。

复用已有精读笔记，将相关论文并排比较：

| 维度 | 研究时提取什么 |
|---|---|
| 问题和主题 | 谁在什么情境下遇到什么困难；哪个未知妨碍理解或行动；论文为何重要 |
| 学术增量 | 最近邻已解决什么；新增发现、解释、测量、方法或设计改变什么 |
| 方法与模型 | 输入输出、机制/假设、选择理由、基线、评价与关键失败 |
| 数据来源 | 原作者仓储、实际文件/变量、时间、许可、可取得性及来源定位 |
| 尺度 | 观察单位、独立样本量、覆盖范围、空间粒度与范围、时间频率与时段、验证/部署层级；计算规模另记 |
| 证据与图表 | 关键图/表/公式所回答的问题、实际结论、例外与支持范围 |
| 可迁移启发 | 可以借鉴的思路、真实适用条件、将改变本研究的哪项设计及对应来源 |

表格是比较维度示例，现有笔记、数据库或叙述也可表达。相同队列或数据的多篇文章按同一来源理解。缺失字段作为下一次定向检查线索，优先查会改变判断的部分。

## 从跨论文规律走向现实瓶颈

归纳领域反复解决的核心问题、成熟做法、不同尺度下的分歧，以及“已经能做”与“仍做不到”的差距。问题可以来自尚未解释的现象、现行决策失误、分配不公、测量盲区、资源不足或技术能力边界。用论文和可信原始实践材料说明问题的真实性；未来工作建议先检查后续是否已解决。

将尚未解决的问题连接为：

现实处境/受影响者 → 科学未知 → 现有方法为何卡住 → 新思路 → 可得证据 → 怎样检验改变。

尺度选择对应实际机制、观测或行动单位。材料可得性帮助设计验证，问题价值先于下载便利；需要转向时，保留问题意义并明确新材料能回答的内容。

## 产生不同问题，而不只是同一算法的变体

先用普通语言提出核心问题，再探索解释、发现、测量、决策、设计、方法与理论等不同切入。新工具出现时，也可反向寻找它真正打开的科学与现实机会。按当前需要复用选题专业Skill，形成可检查的候选而非通用口号。

每个值得推进的候选说清：具体问题及现实后果；最近邻与仍未知之处；预期新增知识/能力；电脑内可取得的材料与研究路径；最有区分力的下一项工作。比较重要性、原创信息、现实相关性和证据可行性，保留有理由的替代路线。候选数量、笔记格式与推进顺序由研究本身决定。

可以创新算法或模型：它的必要性由现实瓶颈或重要科学问题说明；也可以沿用成熟算法发现重要规律。基础理论按其解释力、推理能力与可能打开的问题判断价值。科研价值不由方法类别或一个自动分数决定。

## 让技术进步连接到实际价值

保留技术表现和现实价值两种表达。除适用的预测/求解指标外，说明它与漏检、误报、行动时效、资源利用、服务可达性、环境损失等相关后果的联系。优先比较实际已有方案以及认真调优的简单方法。

能用公开记录或数字实验评估时，明确实际约束与判据。例如，在相同巡检预算下比较提前识别事件的能力；在相同供给条件下比较资源分配结果。技术改善与实际收益的关系由已取得证据或清楚标记的建模假设支持；计算结果、预计用途与真实部署成效分别表述。

## 简洁而准确地命名

先写一句普通语言的核心问题，再形成简短题名。标题保留决定问题身份的对象、现象或行动；数据年份、算法细节、评价边界放到合适的研究设计与结果位置。对必要的情境与条件保持准确，完整意义靠清楚的问题和证据表达。

用两句话检查价值：第一句说明这个领域的什么困难为什么重要；第二句说明本研究将弄清或改变什么、怎样取得证据。面向专家保留精确研究定义，面向非本领域读者保留可理解的意义。没有固定词数或限定词黑名单。

## 交付与续接

选题成果可以是一份简洁的领域综合与推荐题目说明：标杆学习的主要发现、推荐的核心问题、来源支撑、现实与学术意义、最近邻差异、可用数据/尺度、第一项决定性研究动作及有理由的备选。完整稿件尚未形成时将候选与已证结论分开，取得新信息后继续更新。

执行器见 [选题来源](topic-provider-selection.md)。本文件是研究指导，不提供自动选题排名器；研究价值以实际问题、来源、实施和结果判断。
