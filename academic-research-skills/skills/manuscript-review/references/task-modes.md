# 任务模式

focused：局部修改、单图/单文阅读或期刊匹配，直接交付当前请求；不要启动整项目。

publication_research：从重要研究目标推进到实际成果；保存研究承诺与路线板，按需要读研究质量与全生命周期参考。小规模pilot可以验证可行性，但不降低用户的最终目标。阶段决策服务研究，而不是填表。

smoke / engineering_audit：只有用户明确要求技术测试时启用。它的自检、合成夹具、函数演示或其他宿主测试不能作为论文研究已完成的证据；其它宿主测试另需明确要求，本项目不自动启动它们。

开发、优化、更新或打包本套Skill时，处理软件与通用指令本身，交付完整Skill目录和验证记录；这不属于publication_research，不自动选择具体学科课题或撰写论文。
