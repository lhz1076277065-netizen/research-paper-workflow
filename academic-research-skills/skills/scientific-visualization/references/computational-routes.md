# 计算机闭环原创研究：按需路线

仅在选路线或接入专业工具时读取相关行。默认`computational-autonomous`要求材料可在线合法取得或电脑内构造，研究操作由数字工具执行，主要结论可在此证据内检验。路线可组合，不是工具安装表。`research-profiles.json`保留研究类型知识；路由中的画像候选需当前Agent核实匹配，不能把候选当成已完成设计。

## 免费材料取得与评价统一

从最近邻论文的数据声明/附件 → 作者数据代码仓储 → 权威领域来源 → 通用仓储取得候选。OpenML、UCI、Hugging Face Datasets、Zenodo、OSF、Figshare、Dryad及政府/机构门户承担发现职责，每项仍核元数据、字典、代表记录、访问条件与研究许可。公开元数据、免费文件访问和研究再使用分别判断；已有合法账号继续使用，其他权限列外部事项并推进可取得替代。

[OpenML Python API](https://docs.openml.org/python/)提供数据、任务和评价划分的程序接口，适合保存任务ID和同条件比较。[Hugging Face Datasets加载文档](https://huggingface.co/docs/datasets/loading)覆盖远程/本地文件、版本与分区；离线加载需要已有缓存或本地材料，不能凭离线模式取得尚未下载的文件。保留实际版本、查询、分区与原始文件，来源镜像与同队列重复不能充当独立验证。

[Zenodo记录说明](https://help.zenodo.org/docs/deposit/about-records/)区分公开元数据与可能受限文件，[复用政策](https://about.zenodo.org/policies/)要求按具体许可判断。NASA材料按具体数据源核对，[Earthdata登录文档](https://urs.earthdata.nasa.gov/documentation/for_users)说明访问账号机制；免费资源不等于免账号或许可自动满足。

## 按工具接入实际研究

已安装且适配的API、CLI和脚本优先；缺免费工具可按任务下载/安装到实际项目环境并验证。需要桌面功能时用宿主已有GUI能力。R、Julia、C/C++、Rust、GIS、CAD和仿真器由相应运行时或项目承担，Python可协调而不强制替代专业实现。已有授权软件可复用，新增费用或授权单列，继续其他独立工作。

工具操作留最小可复算记录：输入文件/项目格式 → 参数与模型 → 启动命令或界面操作 → 进度、日志和退出 → 结果提取 → 专业量校验 → 可编辑项目与正式成果。GUI成功以真实项目和求解输出确认，不用截图或点击记录代替结果。先用代表小任务测时、内存和数值行为，再定正式规模；问题分解、稀疏、降阶、多保真、流式与分块服务有效研究规模，不能把玩具任务改称完整研究。

工具名是候选，实际版本、接口、平台、算子/精度与许可在使用时查当前官方文档并实跑。此参考于2026-10-01核查的能力入口：[Lean形式化](https://lean-lang.org/)、[OR-Tools组合优化](https://developers.google.com/optimization)、[FEniCS有限元](https://fenicsproject.org/)、[Gymnasium环境](https://gymnasium.farama.org/)、[MuJoCo仿真](https://mujoco.org/)、[RDKit分子计算](https://www.rdkit.org/docs/)。记录被研究模型为`research_model`，与组织研究的`executor`分开；模型权重、训练框架及评价属于研究材料。

## 建设性研究推演

### 从可得代理信息发展估计与设计

延续选择缺失例子，若合法公开材料提供分层S、总体权重w_s、层内p_s与q_s，并有可辩护约束l_s≤r_s≤u_s，则总体界为Σw_s[p_sq_s+(1−p_s)l_s]到Σw_s[p_sq_s+(1−p_s)u_s]。宽度为Σw_s(1−p_s)(u_s−l_s)，显示哪些层的额外信息最可能改变决策；只增加R=1记录未必解决它。核对权重覆盖、层定义、时间与重复来源，不能把其他总体的代理关系直接当约束。

这给出建设性路线：比较最近邻的分层、约束与不确定性处理，再提出更可信的可取得代理、带测量误差的界估计或资源分配方法。新约束必须来自独立公开验证或可证明条件，不能由希望界变窄来设定。开发集估计代理误差，预先留出的独立来源检验迁移；有限样本同时传播w_s、p_s、q_s与约束估计的不确定性。与不分层界、既有方法、去掉新约束及替代代理作同信息比较，报告界宽、覆盖与失效条件。无新增可用约束时，界结论也可能有价值；已有公式本身是基线，投稿增量落在新估计/条件或重要发现，先核最近邻。

### 从资源瓶颈发展算法与可执行设计

某方法在有价值的规模上耗时或内存不可承受时，先剖析读取、搜索和求解，确定瓶颈而非直接缩成琐碎小题。提出结构化候选、稀疏表示、分块或多保真筛选；针对“收益只是少算了难实例”这一替代解释，对齐输入、信息、精度要求和总预算。小实例用已知解/精确求解核正确性和最优性差距，正式留出困难实例及变化工况检验质量—时间—内存与失败率，纳入可信最近邻。

例如先用廉价近似筛选、再用独立高精度求解确认数字设计，要保存未经筛选的对照抽样并检验近似误差是否系统排除最优区域。比较完整策略、去掉筛选、同预算均匀搜索与适用替代，区分“找到更好设计”和“搜索更省资源”的主张。性能未提高时核实现与预算公平性，再改筛选准则、边界条件或发展可信适用范围；不能只展示最佳设计。物理优势限于已校验模型/数值条件，未来实体试验另列。可行管线和已知算法作为基线，原创贡献需要新策略、可证条件或重要边界及决定性证据。
