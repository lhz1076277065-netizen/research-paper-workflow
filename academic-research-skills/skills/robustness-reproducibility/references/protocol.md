# 对抗性检验与复现协议

本协议的专业步骤服从[阶段出口与预算](phase-control.md)：维护/局部请求保持范围；昂贵动作先核主张与成本；两次不同修复或两轮无信息增量必须复评；无可行检验就交付报告。恢复不重置预算或重复完成事项。


> 按任务查阅本参考的相关部分，灵活组合步骤；它不是逐项审批流程。具体输出以用户目标为准。


## 本步如何推进科学论证

依[四段科学论证主线](research-quality.md#四段科学论证主线)，优先攻击贡献成立所依赖的关键解释、假设和测量；每项检查需说明什么结果会推翻或收窄突破及其意义。交付实际反证/敏感性输出与更新后的主张范围，联动图稿和结论。重跑成功只支持已核验部分；无需堆不改变判断的检查，也不能把不利结果排除来保护原故事。

## 威胁驱动，不以显著性驱动

先列出各主张可能失效的原因：测量、缺失、抽样、混杂、模型假设、超参数、依赖、有限信息、分布变化或数值不稳定。检查方案中已预设的检验，再提出有科学理由的新检验，明确事后性质。

不能为了恢复显著性进行无限搜索。一个合理替代分析推翻结果，应记录其对结论的影响，而不是把它标成“不理想所以排除”。

## 适用检验

根据研究设计选择替代变量定义、缺失处理、合理排除、影响点、模型/先验、依赖结构、时间/空间分区、基线、消融、负对照、安慰剂、亚组、外部数据或参数范围。每项写目标与最强替代解释、同条件各自预测、区分操作和结果如何改变判断。预测相同就设计新的数字对照/消融/条件推导，不能多跑相同观察冒充区分。主张决定跨来源、种子、群体、时间、环境范围，不堆数量。

方法验证对齐材料、划分、外部信息、调参、算力和口径；组件比较完整、移除与适用替代，优势和代价同报。模拟分检实现、收敛和适用性，理论分开数值支持、证明与边界。报告方向、大小、区间和实际意义，不只看p值。不能把非显著差异当作等效性证明，也不能因零结果而判定研究无价值。

## 独立重跑

从声明的最早可访问输入到稿件数值重建流程。记录是在全新环境还是原环境重跑，是否取得原数据，重现了哪些表/图/结论，无法重跑的原因。环境快照、依赖、代码、输入哈希与输出记录齐全。

对确定性结果逐项比对；对随机或硬件敏感计算使用预先合理说明的容差，并报告差异。重跑输出相同不等于外部重复研究；换 Agent 解释相同代码也不构成独立科学重复。

## 代码与流程检查

检查数据泄漏、分区、种子选择、共享状态、参数传递、单位变换、取舍、聚合和可视化数值来源。测试缺失文件、空样本、异常输入、失败退出与恢复。无权限的数据不为复现而公开；提供允许的访问与执行说明。

## 主张更新

为每个主要 claim 给出 supported / partial / unsupported / contradicted / unverifiable，写明依据和边界。实验完成度、方法适当性、统计稳健性与外部有效性分别报告，不混成一个“通过”。

检验后主张降级应联动标题、摘要、结果、讨论、图表、期刊匹配与结论。修复一个数字不够，要检查所有下游位置。无法支持核心主张时先提出可执行的增加信息、新方法/目标/算法、更紧界或新设计与检验；也可形成有重要认识价值的负面/边界结论。保留真实结果，更新研究队列下一决定性动作与受影响成果，外部等待单列。
