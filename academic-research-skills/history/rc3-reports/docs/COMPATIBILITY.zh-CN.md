新增三条未见材料任务链，各比较 rc.3、rc.1 与不注入本项目入口，共九次独立任务；另在一个新上下文做四项旧材料/邻近操作。数据链的三组各做两项同 Agent 续接，共六个阶段，不能计为新的独立重复。三次匿名内容审查另列。此前 rc.2 的二十次任务和三次审查继续保留于旧证据，其中包含三次同版重复，不重计为本次新试验。按需求给定冻结能力目录，不认证原生自动发现或全局安装。

所选上游入口与显式依赖绑定 Git blob 身份；匹配当前文件的 reviewed_file_sha256 可保留经复核的本地适配。没有新身份字段的旧描述符继续兼容。未声明传递依赖、实际专业流程与语义兼容需任务相关检查。共同池核验三库二十三个文件，保留来源版本及实际动作；不表示十三库已全部运行。旧完成图只执行相关严格检查，原图字节保持。

十九项入口正文、description 和 UI YAML 均保持，入口共 12,062 字符，单份 592–770。能力可独立使用，不把评估的跨阶段链强加给普通局部任务。三项专家参考经验按任务读取，未向所有入口叠加规则。修改维护源码后仍通过原构建同步副本。
