# 3.0.0 本轮审阅与修复

依据实际alpha.5源码修改，并重新执行测试。此报告是本轮代码、协议和输出检查，不是外部审稿人或CodeRabbit的审计意见。

| 已复现的问题 | 本版处理 |
|---|---|
| 动态fetch用selected-source，bind用仓库::入口，配置不能直接接通 | 使用同一生成标识；测试fetch→config→bind→plan |
| 再次获取源码可能checkout/reset用户的修改，且干净缓存仍需重复fetch | 先核对工作树，干净版本离线复用，变更原样保留 |
| fetch的timeout参数没有传入获取命令 | 传入并校验有限正值；测试实际子进程参数 |
| Contents API不能直接返回部分大文本的Base64 | 使用已索引blob接口回退，仍核对内容身份 |
| 短暂GitHub 5xx或429直接失败 | 有限重试；长限流或权限问题及时返回，不等待无界循环 |
| 安装复制丢失执行位；最小外部Skill导出误依赖本项目研究profiles | 保留文件模式；没有选择研究类型时不读取本项目assets |
| 合法带引号名称不被识别 | 支持对应字符串，并识别未闭合frontmatter与缺失description |
| 带+cpu等本地版本的已装包被误认为不满足数值版本约束 | 以public release部分判断已有稳定包；不将预发布冒充正式版 |
| 已准备的隔离环境再次离线运行仍要求网络；中断创建难以重试 | 验证并复用已拥有的环境；允许修复中断的venv创建 |
| 每份审查被要求覆盖所有稿件、图和日志 | 允许明确的产物角色范围，继续核对实际版本 |
| 新发现的示意图能力被通用数据图分支排除 | 按当前能力的实际数据要求判断，不按模块名封死 |
| 工作图缺省只允许一次尝试，且未比较正在运行的写任务 | 去除隐式次数上限，检查ready/running写冲突 |
| 总控细则仍暗示所有分析必须有数据、每阶段必须填完整字段 | 改为材料/形式命题也可作为证据，阶段记录按实际需要保留 |

真实上游观察：本轮通过GitHub连接器取得SciPilot的export_figure.py，并核对Git blob后实际运行。指定tight=False、grayscale_preview=False的SVG/PNG导出通过。额外检查发现同一快照开启grayscale_preview后会用tight重写原PNG，900×600变为801×586。此项保留为上游版本观察；未修改上游。精确尺寸路线使用已验证参数，预览从独立副本制作。没有把该版本细节塞入日常Skill提示词。

完整回归、原始输出、分析图像与未测试范围见test-results；没有把“所有问题已穷尽”“模型能力提升”“全平台通过”作为结论。
