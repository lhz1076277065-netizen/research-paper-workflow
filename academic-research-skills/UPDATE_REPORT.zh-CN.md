# Academic Research Skills v3.2.0-rc.2 更新说明

交付对象为完整、通用的 Skill 库：1 个可选总控、18 个可独立复制使用的专业能力、16 类可扩展研究配置、general 默认和指定 13 个外部专业来源。新版本基于真实 rc.1 源码小范围迭代；开发测试均为明确标注的固定合成资料。

## 本次实际改动

评估驱动器过去只关联入口和输入，现为每个条件冻结被选模块的完整资源，校验入口、清单、参考文件及材料身份。按需读取可留下实际路径、SHA-256、行范围和显示内容身份；不要求把全部参考加载进上下文。开发复测、同版本重复、新材料和部署体验分别记录。标准库实现沿用既有接口，不引入模型服务或新的 Agent 平台。

研究判断由短要求升级为三个完整可迁移推演：未知偏移与已知校准、选择性缺失与补充抽样、过程材料的时间与来源独立性。例子连接目标、竞争解释、关键推导、实际新增信息、结果分支和不适用边界。research-design 保留原目标并比较新增信息、重设计、部分识别及合理缩小范围；不把缺口一律改成更容易的课题。

主图参考以读者要完成的科学比较为依据：直接效应、总体与子组、关键反例、权重与区间的含义。优先适当的紧凑表达，在目标尺寸打开实际终图；配对差值区间与边际区间分开，固定权重比较保持描述性，已有图合适时可经实质核查后保留。

全文参考突出最强已成立贡献，集中必要限制，区分只取得的摘要与完整证据。专业写作和指定反防御性来源实际作用于完整稿后，比较摘要、引言、结果、讨论、结论、图注及补充中的量值、对象、假设、因果强度、外推和反例；格式变化不重跑分析。

paper-deep-reading 改为从关键论断回到原文/方法/图表/代码的证据，再比较跨资料条件及迁移范围；不因资源、测量或边界贡献的类型先验贬低知识价值。通用科学方法、具体上游版本接口和单项目事实分开。provider-policy 补相关路线的版本核查、实际输入到最终产物的短操作说明、已完成成果保留及真实成本范围。

19 个入口的 description 与正文沿用 rc.1，仅更新版本元数据；字符仍为 592–770，总计 12,062。新的专家细节放在按需参考中。默认自主选择配置、独立模块和专业来源范围均保留。

## 验证与解释

本机共享 Python 3.12.14：完整回归 514/514，无失败、错误或跳过；19/19 入口结构核验；科学工具冒烟 7/7。比 rc.1 的 509 项多出的 5 项覆盖冻结副本、资源修改、范围与身份、重复显示指标以及执行后篡改拒绝。科学冒烟使用制造的解析输入，不能作为实证研究成果。

工程检查、原生独立上下文执行和实际图稿/判断的匿名内容审查分开。当前候选的实际数量、分项好/差/相当/未知及成本范围见源码版质量报告 `evaluations/results/QUALITY_REPORT.zh-CN.md`。日常版省去评估原件；完整源码版保留实际产物、校验和可复核文本。全文开发夹具是测试文档，不能作为真实论文或外部研究证据。

逐次 token、缓存 token、峰值和费用不能取得时保持未知；记录中的资源显示字符只覆盖读取器产生的文本，宿主传输仍可能截断；它不等于模型实际收到的文本、全任务上下文或计费。手动提供入口的效果比较不等于平台自动发现。全学科普遍收益和顶刊录用均未建立。
