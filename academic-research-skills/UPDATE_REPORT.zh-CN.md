# Academic Research Skills v3.2.0-rc.1 更新说明

交付对象是完整、通用且可独立选择能力的 Skill 库。固定合成材料用于软件与 Agent 行为的开发评估，属于测试资料。普通使用不要求先填全套记录或启动论文流程。

## 已实现的两阶段迭代

v3.1.1 先修复五项复现问题：事实复核的布尔类型；终审报告所审稿件的版本；正常研究动作与执行助手范围的区别；文献、阅读、创新操作与当前任务/背景的关联；方案稿交付与未来实证研究完成的区别。旧记录中缺少对象关联的部分需要补真实复核，不用补造收据。

v3.2.0-rc.1 在同一维护源上补强少量可迁移的研究决策例、运行期短操作说明、主图的论证职责与保留合适原图的合法路径、完整写作—科学与引文检查—指定反防御性全文整理—语义/事实对照。路线板仍使用现有文本状态与产物版本，只恢复受影响工作。

十九个入口增加适用时机和范围描述。独立试用发现判断例未被读到，两个相关入口已补直接指向；保留原试用快照后另行复测，没有把保留样例答案写入专业参考。

## 上下文与来源复用

沿用现有发现、快照、交接工具。`upstream.py read` 支持核验已保存文本的 Git blob 身份后复用，缓存改变时保留用户文件并给出具体诊断；不设置统一的小上下文额度。当前 Agent 按仓库、commit、路径和已读片段定位必要原文，大结果留在文件里。

本机实际通过 GitHub 发现指定反防御性来源，读取固定 commit 的英文入口，随后在不允许联网的 CLI 调用中复用同一内容；该接口验证不代表已完成全文整理。完整稿件场景的实际执行和内容审查另见评估记录。

## 保留的结构与边界

保留一个可选总控与十八个独立专业能力、十六类可扩展研究配置、`general` 默认和十三个指定外部专业来源。文献、数据、普通科学软件与原创研究代码有各自的研究依据。参考书、脚本、README 流程与原生 Skill 按真实来源形式记录，不捏造统一调用接口。

当前 Agent 使用现有模型自主完成普通工作，原生内部协作可选。开发环境和本机路径留在运行证据中，不进入通用配置。现有构建、unittest、打包工具与标准库继续复用。

工程结果、Agent 行为和产物质量分开报告。最终实际数量和范围见 `test-results/SUMMARY.json`；源码版另含 `evaluations/results/QUALITY_REPORT.zh-CN.md` 与实际产物。日常版省去评估原件，完整报告也随 GitHub 候选发布提供。发行 ZIP 的 CRC、逐文件 SHA-256 和完整目录身份由打包器核验；GitHub 的发布收据与详细工作路线报告独立交付，避免把尚未推送的状态写成发布完成。
