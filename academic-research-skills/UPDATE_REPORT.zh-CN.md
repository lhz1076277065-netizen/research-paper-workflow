# v3.3.0-rc.2 贡献搜索与发现循环升级

核对基线为 rc.1 发行源码及追加验收提交 494a7021285e502345683a09be6429b982c8f8ce。此前“不发 rc.2”的判断对应当时验收范围；本次用户明确提出五项新的衔接要求，据此升级。旧试验不重新解释为 rc.2 证据。

| 要求 | rc.1 实际情况 | rc.2 维护源改动 |
|---|---|---|
| topic-novelty 从核查走向贡献搜索 | 已有未解问题、近邻和小验证；入口仍偏创新核查 | 实际检验贡献路线，结果改变思路与近邻定位，不以题名未见证明原创 |
| 每项贡献对应最强竞争者与决定性检验 | 已有竞争解释、公平比较；未明确逐项绑定核心贡献 | research-design 连接适用近邻、不同预测、决定性操作与反驳结果；强竞争者缺失时不宣布胜出 |
| analysis-execution 为 discovery loop | 已要求诊断失败、改进方法或边界 | 串联检验、科学诊断、新假设/算法/命题/设计、实际再检验和贡献更新，保留负结果与探索历史 |
| Contribution Escalation 与 Manuscript Backpropagation | 已有科学缺口回研究；写稿阶段缺少明确撤回机制 | 总控、审稿和写作回传弱论断，执行研究并重建受影响图文，撤回写稿就绪判断 |
| 核心贡献先于正式全文 | 允许稿件随成果逐步起草，完整交付义务可能鼓励先填全文 | 正式全文以证据支持的核心原创贡献为触发；未成立继续研究，笔记/方法草稿不算正式论文完成 |

贡献锁定要求重要未解问题、实际核查的最强适用近邻、实质新增知识/方法/设计、公平且有区分力的证据，以及真实输出与支持范围。新近邻、反例或测量问题可重新打开研究。成熟方法产生重要新知识、可靠零结果或理论边界同样可成立；不强制新算法或每个指标胜出，也不把已知原理反例自动认成可发表增量。

局部改稿、翻译、摘要、方案和注册报告保留原范围，不强求未来结果。没有新增管理表、评分器、固定迭代次数或自动原创性判定器；仍是十九个独立 Skill、原有专业来源池和可选记录工具。六个入口和协议、三份公共研究参考连接这些动作；原协议标题及30项写作步骤保留。维护后用原构建器同步独立目录，兼容总控镜像同步，旧工具与历史证据保留。

[工程与发行验证](evaluations/v3.3.0-rc.2/VALIDATION.zh-CN.md)、[独立行为前测](evaluations/v3.3.0-rc.2/BEHAVIOR.zh-CN.md)和[完整总控](evaluations/v3.3.0-rc.2/ORCHESTRATOR.md)分别给出真实范围。前测为合成开发任务，不是发表成果、跨领域版本胜出或通用原创性认证。旧 rc.1 及稳定 v3.2.0 标签和资产保留；本次仍为候选版。
