# v3.1.0 目标与证据映射

| 要求 | 实际维护/执行位置 | 验证范围 |
|---|---|---|
| 在已有v3上升级并保留专业能力 | VERSION、19份protocol、UPGRADE-RECEIPT | 真实底包入口匹配、应用时逐字核对；最终再次核对 |
| 正式研究保持重要科学目标 | research-paper-workflow、research-quality、research-lifecycle | 任务路由与研究记录正/负例；不把Skill更新任务自动变成实际研究 |
| 局部任务不被整套流程绑架 | 专业短入口、research31.assess focused分支 | 局部图表文件检查与错误版本反例；简短任务行为 |
| 外部专业来源限来源清单，实际入口动态 | research31-policy、repository-sources、upstream包装器 | 来源正/负例、等号参数、实时入口与commit；普通文献/科学库不限 |
| 当前Agent和现有模型执行 | 全部19短入口、provider-policy | 本轮原生内部代理操作；无其他助手服务或模型切换 |
| 主图专业设计与真实视觉检查 | figure-production、scientific-visualization | 图表流程及最终版本关联正/负例；本轮不制作具体论文图表 |
| 正式全文专业写作、指定终审 | manuscript-writing、final-expression | 全文范围、指定来源及稿件版本关联正/负例；本轮不撰写具体论文 |
| 文件与步骤记录不冒充科学认证 | research31.py | 记录负例、最终版本关联与明确的科学质量未认证输出 |
| 自主方法与低上下文 | 短入口、按需原协议、可选工具说明 | 原435用例保留；入口与独立目录检查；不强制全部来源或references |
| 完整能力独立可用 | 19个完整目录及assets/scripts/references | 生成副本一致性、独立目录复制/命令；不依赖维护源或相邻能力 |
| 可维护、可打包、保留历史失败 | src/common、src/quality31/payload、构建器、make_package | 单源生成、初始失败和修复后回归分列、runtime/source ZIP内容与哈希 |

软件回归、真实Agent使用、科学成果质量分别评估。具体最终结果见test-results/SUMMARY.json与本轮升级报告；本表本身不是通过证书。
