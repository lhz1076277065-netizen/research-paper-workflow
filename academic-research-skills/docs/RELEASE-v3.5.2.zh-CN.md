# v3.5.2 正式版：自主解阻、有界资料获取与上下文优化

研究获取前规划所需子集、访问方式、累计传输及下载/解压/计算并存峰值。默认累计下载和当前项目文件各最多200 GB（十进制），另保留10 GB磁盘余量；失败、重试、删除和阶段切换不重置传输计数。只有整包可得时允许整包，按需解压。普通登录、免费条款及token沿用实际用户的自主访问授权处理；渠道失败先修复或执行适配替代，不把普通访问问题直接转给人类。

新增标准库research_storage.py：计划、预检、有界流式下载、必要ZIP/TAR成员解压及持久收据；phase可绑定原项目配额，动作前预检、自己的runner周期监控。所有19个独立Skill同步，14仓库专业流程继续必调。模型/方法先按科学有效性、判别力及实测成本选择，不以规模或试验数量表示最优。

精简默认主线与阶段指导、重复移交说明；professional begin默认返回真实指导路径，phase resume默认只给当前任务和最近产物，完整收据/历史仍存盘，--full兼容详细输出。只加载当前阶段必要模式，不能把瘦身作为绕过上游专业流程的理由。

本工具不是OS沙箱；任意外部下载/API/SDK必须另设真实边界，不能声称被脚本自动拦截。旧研究已发生但未计量的传输保持未知。本次小文件HTTP/ZIP/TAR测试不代表已下载200 GB，不继续原科研课题，其本地验收记录保留在源码包；本版作为v3.5.2正式发行。

详见[容量与访问](data-acquisition.md)、[阶段控制](phase-control.md)和[必调流程](mandatory-professional-flow.md)。
