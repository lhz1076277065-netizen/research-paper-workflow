# 本轮发现与处理

| 原实际问题 | 本轮修改 | 检查方式 |
|---|---|---|
| 19个入口重复前置宿主/环境/类型/诚信/契约/模板等文本 | 简短任务入口；公共与工具参考按触发读取 | 字符统计、独立目录、短导出 |
| 静态29候选和旧入口路径限制后续新增/移动的上游 | 默认注册表为空；GitHub当前树发现并生成运行期候选 | 新仓库、新路径、新commit及缺失路径测试 |
| “优先复用”容易被“不重写”解释成不许创造新方法实现 | 明确自主探索、改造或新写代码 | 入口与专业参考复核；非模型能力实验 |
| 导出核心协议却默认打包6份长文 | 默认只导出入口，--detail展开专业参考 | 实际导出与30项写作保留测试 |
| 原写作要求逐段登记和泛化局限清单 | 允许直接起草后反向核对；集中解释真正影响结论的限制 | 对照旧协议，原科学要点和标题保留 |
| 历史execution-handoff再次指定固定写作/图表执行器 | 改为当前选择与最小任务交接 | 活跃目录排查与动态路径测试 |
| 新任务用最新版与运行中固定版本混淆 | 新任务发现，当前索引绑定本次读取/获取版本 | 分支移动后仍读原commit测试 |
| 两个相容的最低依赖版本被当作冲突 | 合并更严格下限/相容精确版本，真冲突仍明确报告 | 上下限与精确pin测试 |
| 本轮新增参考链接沿用根目录写法，导致references内相对路径多一层 | 改为文件位置相对路径，共修正140处生成链接 | 全部活跃Markdown本地链接回归 |
| 安装器对直接依赖数量设40个任意上限 | 删除数量上限；按真实依赖与资源处理 | 41个声明解析测试 |

没有删除来源真实性、相关负结果、数据保护或实际执行记录要求。它们以短原则和产物检查存在，不变成阻止提出研究想法的全局前置审批。

仍待实际宿主验证：自然语言触发、长研究中的上下文选择、模型发挥、全论文质量。静态检查和软件测试不能穷尽所有语言层面的潜在冲突。

链接修复后的首轮出现19项旧测试失败：旧断言一律以Skill根目录解析所有Markdown链接，无法检查嵌套参考文件的标准相对路径。已改为以链接所在文件的目录解析，并继续检查目标存在及位于独立Skill目录内；没有跳过测试。该轮结果保留于test-results/iterations/link-base-correction。
