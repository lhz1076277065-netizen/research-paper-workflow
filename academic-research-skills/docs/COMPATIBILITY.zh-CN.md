# v3.3.0 支持与验证范围

正式版提供计算机内研究路线、主动取得合法数字材料、当前Agent与现有模型自主实施、专业工具复用及原创方法开发指导，并提供有范围的结果与导出检查。保留19个独立能力、16画像、14条按需路线、14个专业Skill来源和原协议；科学文献、数据、普通研究库和原创代码不受该专业来源表限制。

| 范围 | 支持及实际覆盖 |
|---|---|
| macOS ARM64 + 当前Codex | 本机实际Skill研究任务与隔离目录执行；一键安装器Python3.9+，工程脚本Python3.10+。正式归档检查安装、备份/恢复、用户修改保护、重复安装、错误包和异常回退；文件安装与用户下一轮原生加载分别确认。 |
| Linux x86_64 CLI | GitHub Ubuntu runner的Python3.11/pdftotext及3.13/pypdf-only完整工程回归与真实PDF路径；没有据此认证Linux宿主的原生安装/自动路由。 |
| 未覆盖平台/宿主 | Windows一键安装不支持当前POSIX安装器；macOS Intel及其他Agent的原生安装、加载、模型行为尚未验收。目录复制/导出说明属于使用方式，不能冒称这些宿主已通过。 |
| 数字来源与定位 | JSON/CSV冻结结果；Markdown/文本/LaTeX源行、DOCX XML段/表格坐标、可提取文本的PDF页行。扫描PDF无可提取文字时报告未检查；没有OCR、任意Word排版保真或跨格式视觉认证。 |
| 数值与语义 | 声明的主值、区间、舍入/容差、有限单位换算及源定义身份；有限局部英文/文字、表格关系和否定规则。复杂主体/因果含义、未支持数值写法及未知关系保留定位pending。主体总体需显式subject_field；全稿字段只在同来源、结果、文件路径内合并。 |
| 科学与工具 | 软件只核声明、实际文件、数值/源语义及渲染依赖；不自动发现所有论断，不认证源结果为真。各专业工具API/GUI须由具体任务实际使用验证，未完成通用CAD/GIS及全部专业软件操作认证。 |

日常运行包不携带测试题、验收答案、实验输出或开发报告。通用软件自检和格式使用示例继续可用；具体研究的数据、参数、验证分区、预算与结论由当前任务决定。

无法解析的主体、单位或文字关系保留带位置的pending，需要结合真实来源复核，不属于科学否定结论。研究新颖性、方法创造力及论文录用概率由具体研究与使用评价判断，软件版本号不提供保证。
