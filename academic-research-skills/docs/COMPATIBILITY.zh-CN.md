# 3.2.0-rc.1 验证范围

本版是通用 Skill 库的完整候选发行。保留十九个独立能力、十六类可扩展研究配置与 general 默认、十三个指定专业来源。本轮十九份详细专业协议与 v3.1.0 字节一致；这证明本轮保留，不要求今后的改进永久冻结措辞。

工程检查、当前 Agent 行为和成果内容分开评价。`tests/run_all.py` 保存真实运行的用例与失败；`--help` 不运行或写测试结果。构建检查核对维护源与生成文件。selftest 使用制造的解析输入检查软件链路，不能作为研究或宿主自动激活证明。完整结果见 `test-results/SUMMARY.json`；原版本结果留在 previous-release，历史通过数量不能继承为本版实跑。

本机工程环境为 macOS/arm64/Python 3.12.14，环境信息属于测试证据，不是通用 Skill 的硬件前提。现有测试也包含合成 HTTP/来源响应与历史合成底包，不能把它们计作真实上游或模型能力验证。GitHub 的 Python 矩阵结果以实际 CI 收据为准。

本轮固定合成材料包含研究判断、主图与完整全文。未提供本项目 Skill、v3.1.0 与候选版在同宿主独立上下文中运行；共同材料、工具及指定来源条件保持一致。内部上下文沿用当前模型，未寻找其他助手或本地 LLM。平台层能力没有全部禁用，所以基线仅表示“未加载本项目 Skill”。手动加载所给入口不证明平台自动发现。匿名内容评审是同模型的新上下文，不能代替独立学科专家审查。

研究判断先有开发观察，再因入口未指向必要判断例而修正两处导航并复测。该版本变化明确列出，不能把初版与修正版冒充同版本重复试验。主图和全文入口及必要资源在各自运行后保持不变。语义路由只观察描述的匹配；续接只观察已有产物的局部图注编辑。实际产物、操作说明、内容发现和成本缺失见 `evaluations/results/QUALITY_REPORT.zh-CN.md`，不生成统一“顶刊分数”。

专业来源按实际形态与使用范围记录：原生 Skill、参考书代码模式和普通脚本不会统一伪称完整原生执行。全文执行区分实际写作、指定反防御性整理及其后事实/语义复核。未取得的原文、真实学科创新、总体不确定性、完整生命周期、正式投稿和全学科通用提升保持未验证。精确模型标识、试验 token、费用和峰值上下文不可取得，不据文件字符数推算。

日常任务使用当前 Agent 与已有模型，不要求跨宿主认证。独立目录检查只证明所测接口可用。发行 ZIP 的 CRC 与逐文件 SHA-256 证明文件身份，不构成数字签名或科学质量认证。本轮交付对象是完整 Skill 文件夹与开发证据。
