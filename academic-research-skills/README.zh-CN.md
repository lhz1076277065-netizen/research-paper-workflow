# Academic Research Skills · 3.2.0-rc.1

本版由真实v3.0.0源码合并科研质量升级层，并在新副本修正实际接口与维护问题。保留1个可选总控、18个独立专业能力及全部详细专业协议；原包、已有研究材料和历史验证继续保留。

完整研究从重要问题、最近邻工作、知识增量和决定性检验推进。局部改稿、单篇阅读、审图和选刊直接使用对应能力，不额外启动整套研究。入口见 [开始使用](START_HERE.md)；只展开当前需要的参考。

由当前Agent及其现有模型执行，原生内部子代理可选。外部专业Skill从用户指定13仓库中动态选择当前入口或已核验本地版本；普通文献、数据、科学库与原创研究代码不受该来源表限制。不寻找其他助手模型或宿主作为研究前置。

正式主图由选定专业Skill参与设计与制作或实质修订，核对数值并实际打开最终画面。正式全文经过专业审查后，实际使用指定反防御性写作Skill整理论证与表达，保留修改前后和事实核验。单个搜索、IQR、导出或摘要操作按真实范围记录。

工具是可选辅助：可用 scripts/research31.py sources 查看指定来源，用其 upstream 子命令发现真实入口，assess 核对已有记录与文件版本。检查器不判断新颖性、科学正确性或顶刊录用；日常任务无需先填JSON。

Python工具要求>=3.10。明确需要工程验证时运行 scripts/selftest.py；源码版还提供 tests/run_all.py 和 scripts/build_release.py --check。原版首次失败、修复后结果和升级层测试分列；具体执行范围见 [验证说明](docs/COMPATIBILITY.zh-CN.md)。

日常版可复制一个完整能力目录使用，不依赖src或相邻能力。源码版额外保留维护源、回归与历史开发材料。版本号表示本次软件迭代，不表示已验证全部学科或产出顶刊论文。

本套Skill面向各学科，按实际研究类型选择专业路线，不默认绑定研究领域。开发/更新本套Skill时只完成软件与完整目录交付，不自动开展具体论文工作。

本次3.2.0-rc.1修复布尔复核、稿件审查版本、研究动作分类、专业记录关联和方案稿适用性；迁移见MIGRATION.zh-CN.md。
