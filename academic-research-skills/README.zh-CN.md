# Academic Research Skills · v3.4.1

1个总控与18个独立专业Skill，从同一维护源码生成。每个专业步骤必须调用用户指定14库内匹配的真实入口；选题默认调用Orchestra，固定问题使用Scholar问题卡。读取并实施来源流程，finish/check核对当前输入和产物后才移交；缺匹配入口就报障，禁止host_fallback。能力索引含23个真实入口，来源类型、依赖与原生限制分别记录。

完整研究先做有界可行性判断：未给预算最多45分钟；已有总预算直接沿用。主张、最近邻、决定性证据、关键依赖与最小验证先于昂贵工程。专业步骤自动登记，恢复只读当前指令、阶段、步骤路径与关键产物；阶段出口拒绝遗漏已启动工作。两次不同修复或两轮无信息增量触发复评，证据充分即可成稿，无可行检验交付报告。维护和局部写作保持当前范围。

阶段工具只约束经检查的动作和自己启动的进程组，不能保证宿主停止采样。真实token计量按输入、缓存输入、输出分别报告，计量不可用时不声称严格达标。来源准备、专业实施和原生函数执行不是同一件事；当前Mac不冒称通过H100训练或完整工作台验收。
