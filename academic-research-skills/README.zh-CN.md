# Academic Research Skills · v3.5.5

按[稳定研究约定](docs/research-alignment.md)保留原始问题、目标范围和全部必答问题：方法与解释可改，固定科学目标不漂移。“问题→实际检验→有效答案→正文”逐项对应；可靠零结果和反向结果可成稿，未检验/失败不冒充答案。允许已核验部分数据先做显式诊断，正式实验仍需全部必要本地数据。现有专业审稿合并核对全文连贯性和全部主要实验，润色对照实际差异核含义。

完整实证研究默认采用[本地数据全流程](docs/local-data-workflow.md)：研究计划→全部必要数据本地核验→准备与试跑→本机实验复算→科研绘图→论文审查→润色与事实核对。每步保留14库真实调用；200 GB累计下载及项目占用上限不重置。

1个总控与18个独立专业Skill，从同一维护源码生成。完整研究以“真实缺口 → 既有局限或竞争解释 → 本文贡献及判别证据 → 新认知、意义与边界”贯穿选题、设计、实验、图表、写作与复核。固定科学问题保持，假设与解释随结果修订，不能先定结论再挑数据；它是本Skill的论证框架，不是所有顶刊统一的官方录用公式。

每个专业步骤仍必须调用指定14库内匹配的真实入口；开放选题默认Orchestra，固定问题使用Scholar问题卡。读取并实施来源流程，finish/check核对当前输入和产物后才移交；缺入口或依赖先自主修复或切换同14库已核实匹配实现，禁止host_fallback。23个真实入口及原生限制保留，完整研究把当前路线板作为后续调用输入；每篇无需调用不相关仓库。
