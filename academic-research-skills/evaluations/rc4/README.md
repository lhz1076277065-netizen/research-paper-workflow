# rc.4 development acceptance

Read [VALIDATION.zh-CN.md](VALIDATION.zh-CN.md) for bounded engineering, actual digital execution and native output-review findings. [IMPLEMENTATION.md](IMPLEMENTATION.md) maps problems to maintained files and evidence. These are development tasks, not an original paper or a scientific-quality certificate.

Actual public materials retain their source licenses and attribution requirements, separate from this library's MIT code license:

- UCI Wine Quality: https://archive.ics.uci.edu/dataset/186/wine+quality, DOI 10.24432/C56S3T, CC BY 4.0; original work Cortez et al., 2009. Actual archive/dictionary/license page and retrieval receipts accompany `test-results/rc4-digital-final`.
- Native cases' UCI Bike Sharing: https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset, DOI 10.24432/C5W894, CC BY 4.0; preserve Fanaee-T and Gama attribution and archive Readme.
- O*NET Database historical versions used in native cases are attributed to U.S. Department of Labor, Employment and Training Administration (USDOL/ETA). The archived license pages specify version-specific terms; transformed comparisons are the development agents' analyses, not USDOL/ETA approval. Preserve version and notices.

`tool-execution/` preserves actual missing-dependency installation, free scientific APIs, local research-model parameters/reload and live upstream commit/tree/blob records. Runtime environments and caches are excluded. Historical absolute paths and implementation-stage VERSION values remain unchanged.

`native/` preserves one independent context per frozen version with eight new subcases, actual materials/code/results and reading records. These are not eight independent trials per version. Anonymous review copies only mask condition identifiers; originals and their hashes remain available. Download failures, truncation/read limitations and unavailable input artifacts are reported rather than removed.

The final package hashes, exact commit/tag, isolated installer/extracted-package checks and remote CI are recorded in the release's external receipt, avoiding self-referential archive hashes. No global user Skill directory was replaced by these acceptance runs.
