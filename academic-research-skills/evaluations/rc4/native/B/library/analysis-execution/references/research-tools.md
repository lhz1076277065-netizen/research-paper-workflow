# 专业工具的实际研究链（按需）

工具名是候选；选用时读取官方接口、平台支持、免费使用条件和版本，优先已装且匹配的实现。论文、数据和普通科学软件不受外部Skill仓库表限制。

| 类别 | 项目与启动 | 提取与专业校验 | 保存 |
|---|---|---|---|
| R / Julia | 脚本、renv锁或Project/Manifest；Rscript / julia --project | 估计量、区间、分组与留出；对解析/参考解复核 | 源代码、环境锁、结果表 |
| C/C++ / Rust | 源码、编译参数或Cargo工程；实际编译后运行 | 正确性、独立枚举/参考实现、同预算性能 | 源码、构建配置、可执行文件校验值与日志 |
| 数学 / 形式化 | 命题、假设、符号或Lean项目；解释器/证明检查器 | 推导、残差、证明依赖、边界/反例 | 可编辑推导/证明源与实际检查输出 |
| 优化 / 仿真 / 数值 | 参数与实例文件；OR-Tools、MuJoCo、SciPy或领域求解API | 可行性、目标、最优差距；收敛、已知解和模型适用性分别核对 | 输入、模型、求解状态、结果和对照 |
| GIS / 遥感 | 栅格/矢量、CRS、时间与查询条件；CLI/API或已有GUI | 范围、投影、单位、像元/独立区域、时空留出 | 可编辑工程、处理链、原始与派生数据 |
| CAD / 计算设计 | 参数化项目、几何、边界与材料；API/CLI或GUI求解 | 约束、网格收敛、独立求解与变化工况 | 原生设计工程、网格、求解日志和图表 |
| 分子 / 组学 | 来源/许可明确的结构或序列；RDKit/专业API | 解析、结构规范化、分组与化学/生物量的定义 | SDF/序列/矩阵、处理脚本、描述符与结果 |
| 本地科研模型 | 算法/权重版本、许可证、训练与评价划分 | 训练进度、未参与开发的评价、误差/延迟/内存、组件消融 | 配置、权重/参数、划分与结果；executor继续当前宿主 |

每条链完成：真实输入→项目参数→批量启动→观察日志/退出状态→提取量→专业检验→修复/调整→保存原生可编辑项目和成果。API/CLI适于稳定批处理；GUI功能通过宿主已有浏览器/桌面自动化使用，界面动作后读取项目文件与求解输出确认。无法由当前接口完成的步骤注明范围，不把“窗口打开”记为求解成功。

小例用于校准和软件正确性，正式结论另需最近邻、公平比较、决定性验证和相应证据。工具输出直接关联结果与稿件，避免手抄数值漂移。`environment.py exec`提供通用argv执行和文件回执，既有专业软件脚本继续承担计算。
