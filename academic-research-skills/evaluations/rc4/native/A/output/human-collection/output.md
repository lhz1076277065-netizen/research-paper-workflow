## 2. human-collection：把工人访谈问题转为电脑内证据

保留问题：自动化是否把工人的任务从执行操作重新分配到编程、协调和检查。转化后的可回答问题是：在同一个机加工职业的公开调查材料中，数控编程与协调的重要性是否相对传统执行任务提高；这种信号能否排除任务改写和职业分类变化。这个问题仍关乎任务重新组织，但不声称重现工人主观体验或识别自动化的因果效应。

材料路径：[O*NET 官方历史档案](https://www.onetcenter.org/db_releases.html) → 20.0、30.0 文本数据库 → Machinists（51-4041.00）的 Task Statements 和 Task Ratings。两份 ZIP 均实际取得，分别 11,266,024 和 13,462,590 字节。初次猜测 20.0 的新版路径得到 404，已查官方档案链接并成功重试；失败保留在下载日志。官方档案说明所有版本有 Creative Commons 许可，须遵守 [数据库署名与改写说明](https://www.onetcenter.org/license_db.html)。本交付署名原数据为美国劳工部就业与培训管理局 O*NET 数据库；抽取、配对与分析由当前 Agent 完成，原机构没有认可这些修改。数据库原始文件和数据字典保留在 `human-collection/v20_0`、`v30_0`。

实际决定性先导检验：按同一 SOC 和 Task ID 配对，并检查任务文字是否完全相同。两版各有 29 项，29 个 ID 共用，其中 26 项文字相同。测量日期实际为 07/2012 和 08/2020；版本发布年份不是调查年份。共用但改写的 3 项不进入主要任务变化比较。完整配对结果保存在 `human-collection/comparison.json`，包括文字、类型、重要性、调查日期、N 和标准误。

| 未改写任务 | 2012 重要性 | 2020 重要性 | 差值 |
|---|---:|---:|---:|
| 3110：编程数控机床等电子设备 | 3.95 | 4.54 | +0.59 |
| 3116：与数控程序员协调以保证机器/产出符合要求 | 3.70 | 4.33 | +0.63 |
| 3094：按规格加工零件 | 4.57 | 4.77 | +0.20 |
| 3095：测量/检查成品缺陷与规格 | 4.38 | 4.62 | +0.24 |

这些是原数据库 IM 量表的描述性变化。任务 3116 的类型从 Supplemental 变为 Core；数控任务变化方向支持继续检验“任务重组”，但执行加工的重要性也上升，不能写成“自动化消除了执行任务”。同职业代码不等于同工人面板，回答样本 N 各异，且没有工厂自动化采用时间或对照组；不报告未经设计支持的因果效应或伪造访谈。

贡献候选：可复算地分离任务重新加权、文字更新、分类更新与测量日期，把笼统自动化叙事变成可被反例推翻的任务证据。已有 [Acemoglu 与 Restrepo 的原作者框架](https://www.nber.org/papers/w25684) 区分任务替代与新任务效应，本轮只核实其摘要，不声称这个区别是新贡献。下一决定性电脑内验证是用固定定义的匹配任务、更多实际调查波次及负对照任务，检查数控协调相对执行任务的变化是否持续，并排除仅由任务更新造成的信号。材料和计算均可在电脑内完成；因果机制和个人体验目前不在识别范围内。
