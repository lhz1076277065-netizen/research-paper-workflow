# 研究适用性

分别识别学科、文章类型、研究设计、方法与证据材料，允许混合或未列出的研究。方法由问题决定。实证使用数据与设计证据；理论使用定义、命题与证明；人文使用原始文本/史料与解释；定性使用真实材料与分析；综述使用检索、筛选与综合；仿真区分数值验证与实测。

`assets/research-profiles.json`保留16类可组合的提示；`research_router.py --task task.json`可提取当前适用部分，输出不是研究方法白名单。未知类型由宿主查原始方法来源后建立适用路线。

顶刊标杆用于学习优秀问题、方法与图表；按领域加入顶级会议、专著、档案或标准。创新核查的相关证据库不按期刊声望截断。没有摘要、图表或数值的材料按实际结构阅读。

写作参考中的30项对应可能的内容工作，不是固定IMRaD或逐条not_applicable表。只处理会影响本研究解释与交付的事项；完整稿件仍应有清楚论证、真实证据与必要报告细节。
