# 实际研究执行协议

> 按任务查阅本参考的相关部分，灵活组合步骤；它不是逐项审批流程。具体输出以用户目标为准。


## 执行前检查

读取问题与方案，核验数据版本、软件/设备与权限、适用报告规范。区分自己实际观察的状态和上游声称完成的状态。缺失方案时可从材料重建合理方案，但保留已接触结果的事实，不能追认预设。

## 建立可复现执行记录

记录系统、运行环境、依赖/锁文件、软件版本、数据哈希、代码提交或文件哈希、参数、随机种子、硬件与数值容差（适用时）。日志保留命令、输入、输出、耗时、退出状态、警告和失败。代码先做小规模测试，数据/依赖不安全时隔离。

## 正式研究

按研究类型执行真实计算、实验、分析、推导或资料解释。适用时先描述样本与数据质量，再基线/对照，最后主要模型与扩展。结果不可由语言模型凭模式猜测；任何数值、表或运行成功都必须有实际输出。

实体实验、招募、访谈和设备操作未实际发生时不能填执行成功。可完成协议、已有数据分析或计算验证，并把外部工作单独标阻塞。

## 方法特异执行

回归/层级：合适结果分布、依赖、诊断、效应与区间。因果：设计特异诊断、识别假设与敏感性。预测：严格训练验证流程、锁定测试集、基线与校准。SEM：测量和结构诊断、识别、估计与不变性。仿真：数值验证、重复、参数空间与 Monte Carlo 误差。定性：可追溯编码与反例。综述：筛选、提取、偏倚与适用综合。理论：逐步推导、条件与反例。

细节依据本地 method-routing 与核实方法来源，不必把所有模型都跑一遍。

## 数值与解释

每个主要结果包含：问题 ID、分析性质、独立样本/材料依据、数据/代码版本、目标量或指标、估计、单位、区间/误差定义、比较对象、适用检验、诊断和限制。区分相对改善与绝对差、百分比与百分点、标准差与标准误、样本与观察数。

保存未舍入输出，稿件显示值从同一来源按规则生成。没有不确定性估计时记录原因和不能支撑的主张，不能编造置信区间。

## 偏离、失败与冻结

模型不收敛、质量不足、测量无效或基线更好均是需要报告的结果。合理修复须有变更原因，保留前后版本；不能只保存最好的随机种子。方法验证失败时调整主张或设计，而不是改图或删除结果。

冻结可供下游使用的结果清单与全部必要输出。待进一步检验的结果明确 provisional；冻结只是版本稳定，不表示结论永远正确。
