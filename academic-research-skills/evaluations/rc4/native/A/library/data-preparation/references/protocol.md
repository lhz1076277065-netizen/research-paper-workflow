# 数据准备、质量与版本冻结协议

> 按任务查阅本参考的相关部分，灵活组合步骤；它不是逐项审批流程。具体输出以用户目标为准。


## 原始数据只读

核对原始文件的来源与哈希，建立 raw、derived、logs、reports 的逻辑分层；实际目录可适配用户项目。不覆盖原始数据，不以手工改电子表格作为唯一清洗过程。每项转换有脚本、参数、输入输出与版本。

## 模式和测量检查

核验编码、变量名、类型、键、唯一性、范围、缺失值表示、类别、单位、量纲、时间戳、时区、地理坐标系和空间支持尺度。特殊值如 -999、空字符串与真实零要区分。多批次数据检查 schema 漂移、仪器校准和定义变化。

## 样本、重复和连接

区分重复记录、重复测量、独立个体和群组。连接前声明一对一、一对多或多对多关系，检查键唯一性；连接后报告行数膨胀、匹配率、未匹配对象与重复。不能让多对多连接无声改变样本权重。

每步保留样本流：原始数、纳入、排除与原因、用于每个分析的实际独立单位和观察数。来自相同队列/设备的多个文件不自动作为独立来源。

## 缺失、异常和偏倚

报告缺失模式与可能机制，给出处理理由及敏感性；不默认删掉含缺失的所有样本。异常值先核验测量和来源，不能为了结果更好而删。记录截尾、变换、标准化、聚合、插补和异常修复规则以及结果。

检查类别不平衡、选择/幸存者偏倚、标签噪声、非响应、时间和地域覆盖。数据质量报告同时含未能修复的限制，而不只是“清洗完成”。

## 防止泄漏

在研究设计要求的分区内拟合插补、标准化、特征选择与调参。按人、机构、时间、空间或其他实际依赖单元划分。未来信息、目标衍生特征和近重复泄漏要被检查；不能先全数据预处理再声称测试独立。

## 测量和数据融合

变量构造记录公式、单位与依据。时空重采样、插值、配准、数据连接与标签映射须暴露误差和适用边界。定性材料的转录、翻译、编码与脱敏同样保留审计轨迹，不凭空补齐言语或观察。

## 自动检查与人工复核

执行键、范围、约束、行数、缺失和分布检查，并对影响核心结论的记录与转换进行实际检查。描述统计发现问题时回到转换而非直接进入模型。自动检测“通过”不替代测量有效性评估。

## 冻结分析数据

生成 release manifest：输入源及哈希、转换代码、参数、数据字典、样本流、各分区标识、输出哈希、已知问题和生成时间。冻结后任何修改产生新版本，并让依赖的分析、图表和稿件数值失效。受限数据不强行公开，提供可执行访问说明或许可允许的替代复现材料。
