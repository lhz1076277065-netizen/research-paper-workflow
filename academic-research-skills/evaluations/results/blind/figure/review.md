## 独立数值核对

定义 Δ = loss(B) − loss(A)，因此负值表示 B 的点损失较低，正值表示 A 的点损失较低。权重在**每个条件、每个方法内部**计算，不能把 A、B 的相同计数重复相加。

| 条件 / 层 | 每方法 n | A | B | Δ |
|---|---:|---:|---:|---:|
| reference / S1 | 80 | 4.0 | 3.2 | −0.80 |
| reference / S2 | 20 | 8.0 | 9.0 | +1.00 |
| changed / S1 | 20 | 5.0 | 4.8 | −0.20 |
| changed / S2 | 80 | 7.0 | 8.2 | +1.20 |

| 聚合方式 | S1:S2 | A | B | Δ |
|---|---:|---:|---:|---:|
| reference 的给定权重 | 80:20 | 4.80 | 4.36 | −0.44 |
| changed 的给定权重 | 20:80 | 6.60 | 7.52 | +0.92 |
| changed 损失按 reference 权重重加权 | 80:20 | 5.40 | 5.48 | +0.08 |

核算式为 reference：A = 0.8×4.0 + 0.2×8.0 = 4.80，B = 0.8×3.2 + 0.2×9.0 = 4.36；changed：A = 0.2×5.0 + 0.8×7.0 = 6.60，B = 0.2×4.8 + 0.8×8.2 = 7.52。敏感性比较为 changed：A = 0.8×5.0 + 0.2×7.0 = 5.40，B = 0.8×4.8 + 0.2×8.2 = 5.48。

由此可直接确认：S1 中 B 的点损失始终较低，S2 中 A 的点损失始终较低；观察混合下的聚合点排序反转。保持 reference 权重时，changed 的聚合差仍为 +0.08，因此不能把本例的反转全部归因于权重变化。以上均为固定合成点值的描述性运算，未重估任何区间，也不构成显著性或因果推断。

三张 PNG 的八个点值标签均与 CSV 一致；按可见刻度核对，行区间的位置与给定端点相符。图中均未画未经供应的聚合区间。本次未读取绘图源，未进行坐标级程序化审计。

## F1

### 关键比较

**证据：**标题直接指出 “aggregate ranking reverses”。面板 b 同时列出 reference 的 4.80 / 4.36 与 changed 的 6.60 / 7.52，A/B 的左右次序相反；与面板 a 使用相同的 0–10 损失尺度，读者可同时把握层内值与聚合值。

**可改进：**在 b 的条件行旁补上 Δ = −0.44 / +0.92，可以省去读者减法，也能让小差异在缩小印刷时仍清楚。较低损失的方向目前位于底部说明，若图被裁去脚注，轴上没有方向提示；可将 “lower is better” 合并进轴标签。

### 分层反例

**证据：**a 完整显示四组 A/B 点与行区间；S1 的 B 分别为 3.2、4.8，低于 A 的 4.0、5.0；S2 的 B 分别为 9.0、8.2，高于 A 的 8.0、7.0。条件间的水平分隔线有助于避免跨条件误配。

**可改进：**图中没有直接写出 “B lower in S1; A lower in S2”，该解释依赖读者识别左右位置或阅读图注。可以用一句短注释替代部分重复文字，无需新增一个差值面板。

### 聚合权重

**证据：**b 的行标签直接给出 reference 的 S1 80%、S2 20% 和 changed 的 S1 20%、S2 80%；a 给出每方法 n，图注给出 Σ(n×loss)/Σn 及每条件每方法总数 100，运算与固定数据一致。

**可改进：**没有固定权重敏感性比较，读者需要额外计算才能看到 changed 按 80:20 重加权后仍为 +0.08。图注已明确两者的层内损失和权重都变化，所以这不是错误解释；若主要讨论目标是反驳“仅由成分变化造成反转”，可在图注补充这个单一派生结果，不必扩为更多面板。

### 不确定性及适用范围

**证据：**a 的给定 95% 行区间与 b 的无区间加权点在图内明确区分；底部写明无显著性检验及因果识别。图注进一步说明区间构造、计数的抽样单位与独立性均未说明，这一层限定最具体。

**可改进：**可用极短的图注句提醒：行区间不能充当方法差或聚合差的区间。reference/S2 的 [7.5,8.5] 与 [8.4,9.6] 重叠，changed/S1 的 [4.5,5.5] 与 [4.3,5.3] 重叠；图注没有根据重叠与否宣称显著性，处理正确。任何目标人群中的泛化优越性都未由这些合成材料建立。

### 图注及论断忠实性

**证据：**图注的层内方向、四个聚合值、权重、总计数和“无条件 B 总体更优不受支持”的限定均正确；明确不隔离成分唯一解释、因果效应或机制，没有把点排序当作统计证明。

**可改进：**“These results support a conditional comparison” 可进一步点明只是这些给定条件和混合下的描述性点比较。现有文字已足够克制，这属于精确化而非修正错误。

### 布局与信息负担

**证据：**两面板、统一图例、蓝圆/橙方双重编码便于识别；点旁数值和行计数可直接查读，没有遮挡或截断。代价是大标题、双行行标签和底部两行说明占用较多空间，两个面板间留白较宽。

**可改进：**适度缩短标题和重复的 “per method” 标签，并保留一处明确定义；把节省的空间用于 Δ 标签。当前 PNG 全尺寸可读，但参考条件聚合差仅 0.44，在 0–10 全尺度上较小，最终版面缩小后的可读性尚未实测。

## F2

### 关键比较

**证据：**d 以 B−A 为横轴，零线和 “B lower loss / A lower loss” 明确连接符号与方向；−0.44、+0.92 分居零线两侧，反转无需心算。+0.08 的空心菱形把重加权敏感性与两个给定混合结果区分开。

**可改进：**d 不直接显示聚合 A/B 均值，只在图注提供 4.80 / 4.36、6.60 / 7.52、5.40 / 5.48。若读者需要判断损失的绝对水平，可在行标签中加紧凑的 A/B 数字；没有必要再增一个均值面板。

### 分层反例

**证据：**a、b 按条件拆分，但共享相同损失刻度；各面板都显示 S1 里 B 较低、S2 里 A 较低的对应点值与区间。纵向偏移仅为可见性，图注明确说明，未被解释成另一种测量变量。

**可改进：**可在图注将 “B has lower loss” 统一写为 “lower point-estimate loss”，避免脱离后文的无检验限定后被摘读为统计优越性。当前图形数据本身没有遗漏反例。

### 聚合权重

**证据：**c 的百分比堆叠条把 80:20 → 20:80 的混合变化直接可视化；灰度、纹理和数字冗余编码易于打印区分。d 的第三行正确将 changed 损失按 reference 80:20 权重重算为 +0.08，图注提供 A = 5.40、B = 5.48，并明确这是描述性敏感性比较。这使“权重变化不是唯一解释”有直接可核查证据。

**可改进：**图内 “Changed / 80:20 fixed” 可以改为 “Changed losses / reference mix”，让读者不依赖图注也知道固定的是权重。图内 “observed” 应理解为给定合成混合，若改为 “supplied mix” 更不易让人以为来自真实观察研究。该参考权重比较是一个选定的描述性方案，不是预先确定的目标人群或唯一的机制分解。

### 不确定性及适用范围

**证据：**a、b 用供应的 95% 行区间，d 标题明确 “no intervals”，底注说明只是派生点差；图注再次排除聚合/差值区间、显著性、因果识别与机制证据。+0.08 没有被当作有统计把握的 A 优势。

**可改进：**补一短句说明原材料未给区间构造、抽样单位与方法间/层间相关性。不能从 n、行区间重叠或 d 离零的视觉距离推导显著性；也没有足够材料证明这些混合代表实际部署人群。

### 图注及论断忠实性

**证据：**所有层内值、权重、聚合值、三个 B−A 差值均正确；空心菱形的身份和计算对象没有被隐瞒。明确说未限定的总体更优论断不受支持，而没有称 A 普遍更好。

**可改进：**“observed overall ranking reverses” 可改为 “aggregate point ranking reverses under the supplied mixes”。这既保留主要发现，也强调这是合成点值结果，而非样本统计认证。

### 布局与信息负担

**证据：**四面板各承担一项信息：两个条件的层内结果、混合权重、聚合差及敏感性；共享方法配色、灰色权重条和黑色差值菱形保持语义区分。零线、负/正方向、纹理及标注清楚，未见遮挡或截断。

**可改进：**四面板阅读步骤较多，但新增的信息不是重复。c、d 的标题较长，页脚为一长行，最终单栏缩小时可能需要换行；空心 +0.08 靠近零线，不能把它缩小到难以分辨。现阶段只验证全尺寸 PNG，可读性不等于已验证最终出版尺寸。

## F3

### 关键比较

**证据：**c 同时写出 A 4.80、B 4.36 与 A 6.60、B 7.52，聚合左右次序相反；每个点旁有方法名，不必反复回看图例。图内副标题明确更低损失更好。

**可改进：**主标题 “ranking varies by stratum and acquisition condition” 可能被快速阅读为“每一层的排序也随条件反转”，但实际 S1、S2 的层内方向分别保持不变。可改为直接指向聚合排序反转的标题；c 旁补 Δ = −0.44 / +0.92，进一步明确差异方向。

### 分层反例

**证据：**a 四组点全部保留，层内数值和区间清晰；reference 与 changed 之间有分隔线。S1 两组橙方在蓝圆左侧、S2 两组在右侧，与固定数据一致。

**可改进：**在图内加入一句“层内方向保持，聚合方向改变”，能纠正标题的潜在歧义。无需增加新面板或重复画所有方法差。

### 聚合权重

**证据：**a 的每行同时给 n 和 w，b 又把 80:20 与 20:80 直接画成百分比条；底部与图注说明 w = n/Σn，图注给每条件每方法总数 100。聚合数值均正确。

**可改进：**a、b 重复展示权重，可以在 a 仅保留 n，仍由 b 承担权重解释。没有固定权重敏感性点，但图注明确层内损失也变化，因此未把反转归因于权重唯一机制；若讨论重点要求更直接的权重诊断，可在图注补 changed 按 reference 权重后的 +0.08。b 的 “Share of observations” 可改为 “Share of supplied counts”，因为材料未说明 n 的抽样单位。

### 不确定性及适用范围

**证据：**a 轴标签注明给定 95% 区间；c 轴标签注明仅点均值；页脚和图注说明无聚合区间或显著性检验，并排除因果与机制。没有通过把行端点加权而伪造聚合误差线。

### 图注及论断忠实性

**证据：**三面板解释、四个聚合点、权重及层内比较均忠实。图注明确拒绝无条件 B 更优，并写明反转不能全部归因于权重变化，这与独立核算的 +0.08 一致。

**可改进：**主要需要精确化图题而非改写图注。图注中的总体推断已经限定为固定结果，未声称识别了真实采集机制。

### 布局与信息负担

**证据：**左侧集中展示全部层内结果，右侧上下安排权重和聚合，阅读层级清楚；大字号、直接标注、圆/方双重编码和灰度权重条使全尺寸图易读。图内没有可见碰撞或截断。

**可改进：**粗体长标题、较宽双行行标签、a 与 b 重复的权重增加占地。删除 a 的 w 重复项、缩短标题能降低负担。a、c 不同横轴范围应保持显著刻度，最终缩放时不能让读者误把两面板横向距离作同尺度比较。

## 各维度的跨材料结论

- **关键比较与分层反例：**三张图均保留“B 在 S1 点损失较低、A 在 S2 较低”以及给定混合下的聚合反转。F1、F3 以绝对聚合值表达；F2 以带零线的有符号差值表达，读取的任务不同。
- **权重解释：**三张图均准确披露权重。F2 额外直接展示 +0.08 的固定权重敏感性，提供更直接的描述性诊断；F1、F3 的图注已正确限定“双重变化”，没有因为未展示该敏感性而产生错误论断。
- **不确定性与适用范围：**三者均没有编造聚合区间或统计/因果结论。F1 对区间构造、抽样单位和独立性未知的交代更具体；F2、F3 可以补齐这句限定。三者均不能据此证明某方法在未定义目标人群或真实部署中的总体优越性。
- **布局与负担：**F1 两面板紧凑表达基本证据；F2 四面板增加了独立的敏感性信息；F3 三面板把混合明确可视化但重复了行权重。未见全尺寸 PNG 遮挡或截断，最终版面尺寸尚未实测。

没有发现点值、加权运算或主要图注事实错误。需要修订的主要是读者路径与措辞精度，而不是替换数据或制造额外证据。
