# rc.3 synthetic development evidence
These are reviewable copies of actual local executions, not a real research project.
Local paths are replaced by LOCAL_EVIDENCE_ROOT/LOCAL_USER_ROOT. Original and
published SHA-256 identities are listed separately. The requests bind original
frozen resources; reprepare paths and snapshots for a new host execution.
Initial data-chain outputs are preserved separately from same-Agent caption and
input-correction continuations. Anonymous reviews are same-model fresh contexts.
Selected third-party code/dependency/font caches are omitted. Reproduction scripts
that import those helpers require restoring the declared files and pinned versions
from professional/sources.json to their recorded helper/cache paths. This is not
an assertion that the evidence directory itself is an offline runtime bundle.
No full rollout, hidden reasoning, credentials or installed host state is included.
