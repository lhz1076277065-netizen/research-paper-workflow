# chain-c — 合成开发任务路线板

本目录仅用于冻结 Skill 的开发样例。期刊、作者、数据许可、评论及结果为闭合虚构材料；不是真实论文、评审、投稿或发表。

原始工作文件：`baseline/draft-v2.md`。原始请求授权本地改稿、匿名投稿包准备和更正草稿；没有对外动作或作者签字授权。

当前核心主张：在同一组已提供的分层均值下，g1:g2 从观测样本 0.5:0.5 改为预设目标 0.8:0.2，A−B 的点估计由 +1.00 变为 −0.20 score。g2 的 +3.00、目标区间 [−0.60, 0.20] 及未知审批状态必须保留。

| 当前阶段 | 动作与目标文件 | 证据边界 |
|---|---|---|
| 基线与来源 | 冻结读取、逐字节副本、`resource_reads.jsonl` | 不读取其他候选、条件、评分或历史答案 |
| 科学与引文 | `science/scientific-audit.md`、`science/citation-audit.md` | 数值来自 v2 memo；不声称复现或读到全文 |
| 选刊与治理 | `science/journal-selection.md`、`author-requests.md` | Lens v2 Technical Note；声明仍需作者判断 |
| 全文与图稿 | `submission/anonymous/manuscript-v3.md`、图注、补充、图源 | 实际改稿；只绘制已提供的汇总数值 |
| 审稿回复 | `review/response-draft.md`、基线差异 | R1、R5 接受；R2、R3、R4 有据不同意 |
| 更正 | `correction/correction-note-draft.md` | v1 原字节保存；−0.30→−0.20 不抹除历史 |
| 交付与核验 | `answer.md`、`operation.md`、`verification.json` | 本地作者审阅包；未提交、未公开、未签署 |

下一关键动作：完成实际文件和跨文件复核，然后由作者确认身份、贡献、利益冲突、资助、伦理/参与者状态及合法访问流程。本任务不补造新实验、原始数据或批准。
