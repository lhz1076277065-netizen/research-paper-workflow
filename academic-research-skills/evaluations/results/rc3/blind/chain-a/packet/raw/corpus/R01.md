# R01 — fictional 2020 preprint, work W-A
§1. A source H and target G are finite simple directed acyclic graphs. Each
vertex has a label and an integer timestamp. An embedding f is injective,
label-preserving, timestamp-preserving and induced: u→v is an edge of H iff
f(u)→f(v) is an edge of G. Every edge strictly increases time. A path between
distinct vertices has at least one edge; reachability below uses this convention.
§2, claim. For any distinct u,v, u reaches v in H iff f(u) reaches f(v) in G.
§3, argument. A path u=u0→u1→...→uk=v in H maps edge by edge to a path in G.
This establishes the asserted equivalence. No converse argument follows.
§4. Called “trace compression” here; the 2021 article uses “witness export”.
References: R03 for interval-closed images; R05 for deployment documentation.
