# 诱导嵌入复用的精确边界与采用记录的证据判断

这是封闭合成夹具的推导与来源批判。R01–R10 的作品、人物与历史记录均为虚构；以下结果不代表真实文献的新颖性或实际研究成果。

**结论是：诱导性本身不足以保留双向可达性；区间闭合充分但不必要。给定合法的诱导嵌入，精确条件是每条从保留顶点出发、内部只经过被删顶点、再回到保留顶点的外部游程，都能由保留子图中的路径替代。现有记录无法支持“形式结果导致采用”的因果结论。** 数学判断可以独立于历史材料缺口推进。

## 定义与一般证明

沿用 R01 §1：H、G 为有限简单有向无环图，顶点带标签与整数时间戳，每条边严格增加时间。f 为单射，保留标签和时间戳，且对所有源顶点满足边存在的双向等价。记 S=f(V(H))、O=V(G)\S。H 与诱导子图 G[S] 同构。对不同顶点定义正长度可达关系 R_S（在 G[S] 中）与 R_G（在 G 中）。时间戳不要求互异；标签也不要求互异。

正向始终成立：源路径经 f 逐边映射为目标路径。因此 R_S ⊆ R_G∩(S×S)。这正是 R01/R02 的提供论证所完成的部分。

定义外部游程关系

\[
 E_O=\{(a,b)\in S\times S:\ a\ne b,\ \exists\ a\to x_1\to\cdots\to x_k\to b,
 \ k\ge1,\ x_i\in O\}.
\]

**命题。** 在上述模型下，下列两项等价：

\[
\forall u\ne v:\ u\leadsto_H v\iff f(u)\leadsto_G f(v)
\quad\Longleftrightarrow\quad E_O\subseteq R_S.
\]

**必要性。** 若双向等价成立，对任意 (a,b)∈E_O，定义给出目标中的 a→…→b 路径。逆向可达性蕴含 G[S] 中 a 可达 b，故该对属于 R_S。

**充分性。** 假设 E_O⊆R_S。取 G 中任一不同保留顶点 a、b 间的路径，并按它先后访问的保留顶点拆成连续段。每段要么是一条保留顶点之间的边，要么内部全在 O，是 E_O 中的一项。前者已在诱导子图中；后者按假设可换成 G[S] 中的路径。连接这些替代路径，得到 G[S] 中从 a 到 b 的有向行走。每条边严格增加时间，故不可能重复顶点；它是一条正长度路径。经 f 的逆映射得到 H 中的路径。加上已成立的正向，得到双向等价。证毕。

所以对一个给定 f，先验证注入、标签/时间戳及诱导边条件，再验证该关系包含即可。若问是否存在某个可复用嵌入，则要求存在满足这些条件的 f；本次没有实现所有候选映射的搜索或最优化。

## 两个最小反例与一个区别性检验

所有下例标签均为 z，顶点身份不同，时间戳分别为 0、1、2；f 是保留顶点的包含映射。

1. **诱导性不足。** G 的边为 0→1、1→2，S={0,2}。H=G[S] 的两个顶点间没有边或路径；G 却有 0→1→2。因此正向成立，逆向失败。两个顶点的目标图不能构成这个反例：不同保留端点之间若存在路径，只能是一条边，诱导性已保留它。故三个目标顶点、两个源顶点是最小规模。
2. **区间闭合不必要。** 为前图再加 0→2。H 含该边，保留端点之间的可达性与 G 一致；但 0→1→2 的内部顶点在 O，违反区间闭合。这也只用三个目标顶点。因此 R03 的充分条件严格强于所需条件。等价地，区间闭合要求 E_O=∅，精确条件只要求 E_O⊆R_S。
3. **替代路径不必是一条边。** 时间戳为 0、1、2、3，S={0,1,3}，G 的边为 0→1、1→3、0→2、2→3。外部游程为 (0,3)，诱导子图中没有 0→3 边，但已有 0→1→3 路径，双向等价仍成立。因此不能把较弱检查误写成“每个外部游程端点间必须已有直接边”。

这些都是按模型构造并证明的反例，没有借用 R04 的不匹配假设。

## 已实际完成的有限核查与证书边界

已运行 [reachability_check.py](ANONYMOUS_PACKET/S2/reachability_check.py)，原始结果保存在 [results.json](ANONYMOUS_PACKET/S2/results.json)。程序独立用 DFS 比较目标可达关系与诱导子图可达关系，并用只在 O 内继续搜索、回到 S 即停止的另一过程构造 E_O。它覆盖时间戳按顶点序号排列、常标签 z、0–5 个顶点的所有 DAG 及全部保留子集：

| 实际检查 | 结果 |
|---|---:|
| 不同目标图 | 1,100 |
| 图与保留子集组合，含空集与单顶点边界 | 33,867 |
| 双向等价成立 | 30,093 |
| 双向等价失败 | 3,774 |
| 区间闭合成立 | 26,433 |
| 双向等价成立但区间闭合失败 | 3,660 |
| 精确条件与直接可达性比较不一致 | 0 |

这核查了实现及这些有限结构，不能代替上述一般证明，也没有枚举全部标签/原始时间戳模式。程序还验证了非法逆时间边会被拒绝。

**检查方法。** 只需从 S 中有出边进入 O 的顶点出发，搜索 O，记录下一次返回 S 的端点；再在 H 中检查这些 E_O 对是否可达。该关系和保留子图可达关系可用于重复回答保留顶点查询。相对于 R10 的所有保留对基线，它的区别是定位真正可能引入额外可达性的外部段，而不是重复证明正向。

稀疏示例 G={0→1,1→2,2→3,1→3}、S={0,1,3} 中，只需检验外部对 (1,3)，而全部按时间可能可达的保留对有三对。但**没有得到普遍紧凑性或速度保证**：若 k 个保留顶点指向唯一外部顶点，该顶点再指向另外 k 个保留顶点，只有 2k 条目标边，E_O 却有 k² 对。程序取 k=8，实际产生 64 对。朴素构造若有 b 个出界起点，最坏需 O(b(|V(G)|+|E(G)|)) 搜索；随后朴素源图检查需 O(b(|S|+|E(H)|))，存储外部关系可达 O(|S|²)。

因此本次结果完成了正确性与严格较弱边界的证明，尚未完成 R10 所提出的最小或普遍紧凑证书。**下一项最有信息价值的数学调查**是：在明确的稀疏出入界结构上，能否压缩 E_O 并优于 R10 的公平基线，同时保留返回缺失端点对的失败证据。成功判据是等价性证明加相同输入下的存储/构造成本改善；若外部关系必然二次膨胀且无法压缩，也应报告该边界，不改成正向问题掩盖失败。这里只能称“提供片段之外的推导”，不能宣称全球首次。
