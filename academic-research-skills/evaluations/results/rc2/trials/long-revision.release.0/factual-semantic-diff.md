## 指定英文终审的实际作用

完整专业稿形成并数值复核后，在当前 Agent 内将 `anti-defensive-writing-en` 应用于全文。原稿中反复自我削弱和过程流水账已在专业写作阶段清理；指定终审进一步把标题、引言和贡献段改为已成立答案，把版本修订说明从材料段及图注移出正文。摘要、结果、讨论、局限与结论逐段复核后，保留了清楚且准确的表达。终审前稿与终稿均为完整稿，没有以摘要代替全稿。

采用项目 `final-expression.md` 的证据保持适配：不执行上游“只讲优势”“换到赢的指标”或省略不利结果等会改变本材料科学含义的规则；不虚构合理权衡或解释机制。C1 G2/G3、C2 G2/G3、N1 仅摘要、探索性和所有缺失推断边界仍在终稿中。

## 实际检查及限制

`check_manuscript.py` 使用 Python 标准库与 Decimal 复算全部目标均值、固定权重均值和差值，核对六行表格及所有区间、簇总数、权重和、五个受影响章节的更新传播，并检查旧值残留。初次表格选择误把标题行算入数据行，修正检查器后重新通过；指定终审之后再次通过。`check-receipt.json` 记录实际终稿哈希与 PASS。

当前 Agent 另按上表核对比较对象、范围、单位、因果强度、配对结构、区间跨零、反例与证据层级。自动检查不替代这些语义判断；本次没有独立人工审稿、原始数据重分析、总体区间估计、交互检验、外部核验、期刊规范验收或版面渲染检查。
