# Scientific visual review — actual rendered figures

SciPilot profile and chart-choice guidance were applied before drawing. The real profile had 300 main result rows, 10 intended groups and 30 scores per group. Figure 1 renders 300 actual scores; Figure 2 renders 240 actual paired differences plus two legend symbols. plot-data.csv contains all 540 scientific positions, taken directly from saved matched results. No confidence interval or significance annotation is present. Figure 1 black ticks are descriptive means.

Both color PNG previews and both grayscale previews were actually opened with the image-reading tool before final SVG/PDF export. Eight checks: glyphs and minus signs render; text is not cropped; labels/legend do not cover data; panel label style and left margins are consistent; two dataset facets do not intrude; blue/orange and circle/square markers remain interpretable in grayscale; all values including 100% and the full negative paired range lie within the plotting region; units and the shared accuracy scale are consistent. Jitter is vertical only and cannot change any data value. Coincident majority predictions form a narrow strip; the explicit n=30 label and source CSV prevent that overlap from masquerading as fewer runs.

Programmatic checks validated every text bounding box against the declared 6-inch canvas and every plotted value against the axis range; smallest type is 7.5 pt. Current-host rendering uses embedded Arial TrueType in PDF and editable SVG text/shapes, with no raster embedding in SVG. Native SciPilot check_figure.py --strict passed PDF, SVG and PNG for both figures at requested physical sizes and 300 dpi tolerance. Native profile_data.py and check_figure.py executed; native matplotlib setup/visual_qa/export functions did not execute because the current-host rendering adaptation was used.

Caption 1: Balanced accuracy for all 30 predetermined 80/20 class-stratified holdouts per method on each original UCI table. Orange squares are training-standardized variants and blue circles are raw/majority arms, redundantly labeled by row. Black ticks show means. Holdouts share observations and represent descriptive partition variation, not 30 independent samples.

Caption 2: Within-split training-standardized minus raw balanced-accuracy change, in percentage points. Each dataset/family shows all 30 matched differences at 20% test (blue circles) and 30% test (orange squares). The vertical black line is zero. Patterns retain positive Wine and negative mean Iris changes. No inferential significance or independent-population stability is claimed.

Human/non-peer comprehension review and actual target-journal approval were not performed and are not prerequisites for this teaching report. This is an Agent numeric/form/visual review, not a publication-readiness certificate.
