# Evidence appraisal and actual reproduction

ER-20261013-reproduction-01: The local 80/20 experiment was actually rerun to a separate replay directory. All four deterministic outputs (predictions, metrics/confusions, scaler parameters and summaries) matched byte-for-byte. A separate standard-library Counter implementation recomputed all 600 main plus sensitivity metric rows from saved predictions, with largest floating difference 2.22e-16 and exact confusion-count agreement. Sixty main scaler records were independently checked against original raw-table numbers with math.fsum. Derived tables preserve every original source row exactly. This proves reproducibility of these computations on this environment, not independent population replication.

ER-20261013-sensitivity-01: The prespecified 70/30 analysis ran 300 additional fixed-arm fits. Mean paired scaling changes in balanced accuracy remained positive for Wine centroid (+0.2625) and Wine 5-NN (+0.2704), and negative for Iris centroid (-0.0637) and Iris 5-NN (-0.0178). All positive and negative splits were retained. No new hypothesis, hyperparameter or preferred split fraction was chosen after these results.

Strengths: Source files and source versions are explicit, all required contents are local, both datasets were checked before fitting, transforms use training rows only, all comparisons share fixed partitions, raw and scaled arms are both retained, actual predictions are auditable, and the implementation reproduces.

Important limits and remedies: (1) Repeated holdouts overlap, so split SD is descriptive rather than an independent-sample CI; report no inferential significance. (2) Iris has repeated feature vectors and no identifiers establish distinct plants; explicit per-split duplicate-overlap counts accompany the report, and no independent external generalization claim is permitted. (3) Two historical teaching tables and narrow fixed baseline families cannot support a universal model choice. (4) Original Iris version has documented discrepancies; preserve its identity and state that a corrected version is a different analysis. (5) NumPy implementation is transparent and checked, but no separate native sklearn or external peer review is claimed. These are scope limits for the intended teaching reanalysis, not hidden evidence of novel scientific efficacy.

Overall decision: The intended descriptive comparison is supported sufficiently for figures and a teaching report. The original universal-scaling idea is not supported; its counterexample on Iris must appear prominently. No additional research expansion is needed to make the already stated bounded claim. Scientific appraisal is performed by the current Agent, with no human/cross-model review credential asserted.
