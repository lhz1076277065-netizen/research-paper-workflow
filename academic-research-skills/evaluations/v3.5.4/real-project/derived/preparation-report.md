Scope: Both required original UCI tables are fully local. All 178 Wine rows and all 150 Iris rows were parsed, with 13 and 4 numeric features respectively. Added documented headers only in derived CSV files; raw originals are preserved byte-for-byte. No model has been fitted, no scaler computed for use in fitting and no rows or outliers removed.

Data dictionary: official wine.names identifies the first column as class, then 13 constituents; some chemical feature units are not supplied and remain unknown. Iris fields are sepal length/width and petal length/width in cm, with species label. Complete original iris.data is the selected version; its dictionary notes historical differences in rows 35 and 38. No silent corrections. Class counts Wine 59/71/48 and Iris 50/50/50 reconcile with dictionaries. No missing or nonfinite feature values were found; no imputation is warranted. Per-feature mean, SD, median, IQR, MAD, minimum, maximum and IQR-fence flags are in feature-summary.csv. Flags are retained observations, not exclusion criteria.

Observational structure: historical wine samples and plants, no supplied subject/site/batch identifiers adequate to certify independent sampling. No temporal, causal or prospective population claim follows. Wine has no repeated feature vectors; Iris has 3 duplicate excess rows. Fixed class-stratified row holdouts can place equal feature vectors on both sides; overlap counts are saved for every split and will be reported as a limitation, not concealed as fully independent external validation.

Preparation: 120 fixed partitions (2 datasets x 2 fractions x 30 seeds) were generated before any learned preprocessing. Every partition has disjoint row indices and covers all rows, with all 3 classes in training and test. The only future learned transformation is z=(x-training_mean)/training_population_SD, with zero SD replaced by 1. Its fit will occur only in the training set. No parameter/model selection is planned. Raw and standardized results both remain necessary.

Native professional execution: K-Dense capability_manifest.py confirmed derived .csv support and tabular_profile.py scanned all rows using max-rows 1000, above each entire table count. This is a complete table scan for these two small files; the tool is generally bounded and is not a universal scientific data-quality certification. Observed profiles and exact manifests are saved separately. Extra Python code validates dictionary-specific schema, builds partitions and reports duplicate overlap; no unsupported original .data suffix was falsely passed as an automated format.
