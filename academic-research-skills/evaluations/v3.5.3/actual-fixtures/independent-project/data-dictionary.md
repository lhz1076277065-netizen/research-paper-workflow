# 数据字典与适用范围
合成人为测量校准教学附件；未知随机生成机制，不是实测或医学数据。全文件UTF-8逗号CSV已核验120行。每行是一对参考和传感读数；4个batch为相关性单元，每批20 train/10 test。原始文件不修改、不去异常、不插补、不标准化。

|列|角色与类型|单位及约束|
|---|---|---|
|batch|人为批次标签，整数0–3|分组单元；不是独立受试者|
|reference|理想参考目标，连续float|附件未命名物理单位；有限实数|
|sensor|原始传感读数，连续float|与reference同附件单位；有限实数|
|split|原设训练/测试标签|train/test；训练参数仅从train拟合|

缺失代码仅空白；未见缺失、非有限值、整行重复。检测限、饱和、时序与物理可接受区间未提供，不能臆定。训练reference区间和测试reference区间见data-context.json；测试区间检查用于边界说明，未据此改变模型。
4个batch均在train和test，不是批次阻断的外部验证。训练LOBO作为更严格的内部压力测试；保留原划分以检验同批次新读数。原生泄漏屏幕报告1个重叠token但逐组重计4个，以实际计数为准。无因果/总体计量效用推断。
