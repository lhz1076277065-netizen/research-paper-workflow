# 独立匿名方法评阅：P 与 Q

本评阅仅接触 method-blind 中 P、Q、共同 method-input 和公开来源；未读取版本映射、原作者目录、其他评阅或历史诊断。分别评价四个维度，不合成总分。评阅对象是本次已交付的探索性方法工作，不把未来调查计作已完成实验。

两稿均合理保留必要的方法发展：定义家庭支持的户外条件、检验土地代理、推导能识别什么、决定补哪些联合信息。这不应因没有包装新算法而判为失败；反过来，正确复用成熟界也不能称为已创出新算法或已经证明发表新颖性。

## 复运行与关键结果

完整盲包复制到 `/tmp/method-review-037i7x1h/method-blind`，使用指定 Python 环境运行两脚本，均退出0。P结果JSON全部一致；Q仅运行时长变化，其他结果一致。P的4个CSV、Q的4个CSV均与原包逐行一致，原盲包未修改。

P复核得到42个完整UHF：2014无空调—树冠 Pearson −0.280693、Spearman −0.214668，Pareto前沿仅Hunts Point–Mott Haven；2017无空调—植被 Pearson −0.043919、Spearman 0.053524，前沿6区。Borough赋值背景的组间差为2014 −0.226956个百分点、2017 +0.081493个百分点。按空调数量／舍入比例恢复家庭数，在同一Borough对各户赋同一环境值，是其声明的地区背景目标；它不测家庭真实可达性，也不证明差距精确到这些小数。

Q复核得到2017无空调—植被 Spearman 0.053524，无空调—2018单日地表温度0.161608。三种分位筛选分别保留6、4、3区；交集为 High Bridge–Morrisania、Hunts Point–Mott Haven、Williamsburg–Bushwick。它只能叫对这三种门槛稳定，不能叫对调查误差、气候年份、指标定义或2026年需求稳健。

原始空调记录958条、缺值60条；2023年Subboro 31／781有89.4957与95.6475的一对冲突记录。Q单列两条而未静默平均，当前2017分析不受影响。P只选择历史UHF和Borough，亦未让重复进入其主分析，但没有同等明确的全文件冲突说明。2014／2017 UHF均42条、无缺值、无CI，分别13／25条有小样本提醒。2023年PUMA2020有55条，其中20条缺值；不能以同号GeoID跨类型硬接。官方有／无空调历史比例相加最多偏离100达0.1个百分点；两稿的“无空调”计算实际采用100减781，应保持这一舍入口径说明，不假定与1045逐条精确一致。

## 原始定义与概率核查

官方冻结元数据确认：781分母为家庭，708分母为除内陆水体后的土地面积，690为地区植被覆盖，688为2018年7月17日白天地表空间平均。土地分母不能当家庭不足边际；地表温度也不能直接解释为长期空气温度或因果降温效应。两稿对此均谨慎。[官方冻结定义](https://raw.githubusercontent.com/nychealth/EHDP-data/d3558441d122b4db4b9fd4d2011be500df6b584a/indicators/metadata/metadata_pretty.json)

在同地区、同年、同家庭总体中，令 p=P(A=1)、q=P(Y=1)、j=P(A=1,Y=1)。四格为 j、p−j、q−j、1−p−q+j；非负约束给出

`max(0,p+q−1) ≤ j ≤ min(p,q)`，

`Δ = j/p − (q−j)/(1−p) = (j−pq)/[p(1−p)]`。

本次独立从四格风险差重算而非只调用作者的bounds函数，核对了两稿代表例及边界邻近例，公式成立。0<p,q<1时独立点pq严格位于端点之间，因此该区两种方向都可相容；q=0或1时风险差为0，p=0或1时比较量不定义。所谓锐界指确定边际下的可行范围；抽样估计的p、q需要联合误差处理，不能把锐界直接称置信区间。

P的Hunts Point构造p=0.257、q=0.92916得到 Δ=[−0.275642,+0.095343]，两端四格有效。该q来自未经验证的1−树冠桥接，作者明确承认是假设，不能据此报告真实户外不足比例或真实识别区间。它展示“在某个更强信息设定下仍不能判方向”，并不修复土地—家庭错位。称“有利假设”仅应理解为多给一个边际约束，不能理解为经验上可信或必然有利于资源分配。

Q的Hunts Point构造p=0.167、假想q=0.5、N=1000得到[0,167,500,333]及[167,0,333,500]，Δ为±0.600240；它更干净地避开土地桥接，但0.5与1000同样不是当地实测。Q明确区分：当前连家庭q都没有，且无可辩护映射限制时，区内Δ只有逻辑范围[−1,1]；给予q后的界只是条件能力。此区分成立。

两稿的情景均不是与所有重叠官方地理边界同时相容的全市微观重建；它们也没有声称完成这种重建。若后来加入地址、家庭占用、代理误差界或其他有效限制，必须保留约束重新求界，不能沿用违反新增约束的反例。两稿都保留了这一发展空间。

P专门指出区内不识别不能机械升成全市不识别，这一点正确且有信息价值。本次另构造两个等家庭数地区，p=(0.9,0.1)、q=(0.9,0.1)：两区各自差值界都含0，但全市家庭加权锐界为[0.6,1]。Q也声明市级需权重及子群分布，未以区内反例报告市级精确差值，不过没有P这样直接展示层次差别。本包缺UHF家庭数与家庭q，不能由此算现实市级家庭差距。

## 最近邻与方法发展

直接方法前作[Wakefield（2004）](https://www.stat.purdue.edu/~chuanhai/teaching/Stat598A/Wakefield_Ecology.pdf)第3.7节（式13—14）讨论同一2×2表边际约束下的真实个体比例界，并区分有限总体比例与模型概率参数；这与两稿四格推导相符，也说明为何土地和家庭比例不能任意拼成同一表。该文的联合调查方向已有前作依据，当前没有必要仅为“方法创新”换成更复杂的预测模型。

[Glynn与Wakefield（2010）](https://pmc.ncbi.nlm.nih.gov/articles/PMC2885825/)的公开检索正文第2节及第7节／表2也表明：同一表边际留下内部计数未识别；补充个体调查需与汇总信息在同一总体内建模。直接PMC访问受验证码阻挡，BioC获取429，但检索返回正文段落可用于核查这些条件；Q所称“第3节式7”的精确编号未独立完整核准，不因数学核查通过而替作者背书该页码／编号。

P引用Romitti的细化空调预测方向，Q引用Li的人口加权降温方向，都抓住真实近邻与目标的差异。此次对Romitti仅取得出版方摘要，不能声称完整核准其全部模型及局限段。对[Li等（2024）](https://www.nature.com/articles/s41467-024-51355-0)实际读到Methods和式3—4：100米人口权重修正一般居民位置分布，并未提供无空调家庭分布；Q的这一辨别成立。它仍是遥感降温指标，与公共地点实际开放、个体行动能力和热天使用的Y不是同一测量。Rosenthal全文和Council地图本次未成功完整读取，作者相关具体段落断言保留，不当作已独立核实。

P已做的代理选择、区内／市级和信息宽度讨论更广；Q的原始／条件信息区分更直接，三变量门槛也更便于复算。这些是不同维度的长处，不能合成为版本优劣或版本因果结论。检索属于定向核查，未穷尽新近前作，故无法确认最终发表增量。

## 下一动作是否真正可执行、是否有信息价值

P的`N_g w_g / ΣN_g p_g`正确对应：在地区可行集合按独立边际盒约束、其他信息不变时，精确取得该区j最多去掉全市无空调组不足率中的该块识别宽度；它不是采集成本调整后的预期信息收益，也不是健康获益。举Hunts Point w=0.07084与Bedford Stuyvesant–Crown Heights w=0.175919，确实说明严重度筛查和信息采集排序可能不同，但缺真实N和q时不能排序现实调查投入。

Q的已知q后补r=P(Y=1|A=1)得到`Δ=(r−q)/(1−p)`成立。只有p、q、r属于同一地区、时期和家庭定义，并处理各自误差、纳入概率及非响应时，才能据此作人口比较；不能把2017发布p与未来调查r直接混用。CSV中`100/p`只是均匀筛查下期望遇到100户无空调家庭所需筛查量，不是精度或检验效能支持的正式样本量，更不是今日招募保证。

两稿都给出能够改变研究方向的观察：联合差异弱时转向总体户外缺口／无空调本身，差异为正时再研究可改变障碍，异质方向则分区报告。其信息目标合理。不过先获取地址级家庭调查、现场开放／热负荷与实际使用资料，需要调查实施或数据访问支持；在本任务公开数字材料／电脑条件下尚未实现，不能按已完成联合实测验收。

更具体的近期电脑动作应先是可取得性与测量审计，而非只宣布要做调查。公开[2023 NYCHVS代码本](https://www.nyc.gov/assets/hpd/downloads/pdfs/about/2023-nychvs-puf-user-guide-codebook.pdf)第32、83、84与318页已有CENTRALAIR、ACUNIT和AC_OFF，户级FW与80个重复权重可用于估计误差。可以先核实对应公开微数据和跳题、非响应、年份及可用地理尺度，再重算“设备正常”与“因费用少用／不用”的差别；但AC_OFF的适用对象有限，不能机械将不适用／缺失编码算为无费用限制，也不能据代码本声称已取得地址级路线联接。公开路径与遮阴场所资料可作为下一项可取得性检查，再明确哪些Y部分仍需现场验证。此次评阅未下载PUF或建立该空间联接，故这些仍是建议动作，不是新增实测结果。

两稿共同还需在正式设计前固定目标：是家庭组间差值、双重不足人数、补信息价值，还是某项干预的预期净收益；这些量需要不同分母和设计。筛查可优先取得资料，但不能将未入选区视为低需要，不能把家庭劣势直接解释成植树或空调补助收益。健康／舒适结局、成本和效果比较尚缺，保留干预排序判断。

## 验收边界

两稿已完成可复核的历史地区比较、成熟概率界推导和清楚标记的构造，并据此合理修订问题；支持继续以测量和资料优先取得为目标。它们证明／展示的是特定信息条件下的不识别及测量需求，不是已创造新算法，也不是已经测到现实家庭不平等、当代干预排名或健康收益。可执行性认可计算阶段；真实联合测量与公开材料上的前置操作路线仍需补足。四个维度分别保留上述结论，不给总分。
