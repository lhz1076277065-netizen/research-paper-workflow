# 盲化比较评阅

只阅读R1、R2；未读取版本、实现、映射或其他任务材料。以下“优／相当／弱”均表示**R2相对R1**，逐项判断，不合成总分。评阅对象是选题设计；产物自述的阅读轨迹、样本可用性和效果不视为已认证事实。

| 维度 | 判断 | 具体支持与边界 |
|---|---|---|
| 真实需要与证据 | 相当 | R1用“前期误报花光钱，后期大洪水无钱可用”解释实际风险；R2用有限预算的优先级失效解释风险。两者均有IFRC实践链支撑，但都没有具体地区EAP证明跨流域共用汛期资金的制度、成本与时限，也未证明所提瓶颈在当地优先于执行能力。R1较易沟通，不能因此认定需求已验证。 |
| 跨篇科学未知 | 优 | R2将预报改善到行动价值的缺口拆成可靠性迁移、暴露与行动时间，并提出区分三者；R1主要转向跨事件资金保留，尚较接近宽泛的策略评估。两者都避免把Sauer的关联趋势当作预警因果效果；这些论文仍不能直接证明所提机制是主要瓶颈。 |
| 最近邻增量及检索缺口 | 优（暂定） | R2除两阶段行动与概率资源优化，还列出多地区多阶段分配、马里全球预报评价，因而把增量收窄为“禁用目标域流量标签时的迁移误差与失效边界”。R1的“连续预报＋多个过程＋未校准流域迁移”仍是较宽的组合差异。R2最近邻覆盖更有针对性，但新增文献不能凭引文数量认证；全文与同机制研究的检索仍不充分。 |
| 模型必要性 | 相当 | 两者先固定已有预报，均不要求新网络。R1只有校准影响资金选择才加校准；R2把校准作为待检验机制，并在决策误差仍主导时才改算法。R2需要概率映射，但尚未证明档案提供所需输入；它提出的重建实验可能明显增加工作。 |
| 数据、独立单位与尺度 | 优 | 两者都给出2014—2018交集、单位与日期处理，并按洪水过程和流域分组。R2额外明确“模拟无站”不能冒充真无站、FLODIS与Sauer共享来源不算独立复制、实际淹没只用于事后评分，以及区级分配和非事件标签问题。仍未给出流域到区级的映射规则、具体地区或最小可用事件数。 |
| 第一项决定性研究 | 优 | R1先审计日期／流域匹配与信息时点，再用同预算、调优基线检验简单保留规则，路径清楚。R2进一步核验整流域留出、概率输入和连续非事件日，能及早发现无法估计迁移或误报开支的硬障碍；固定一个地区和一种行动也减少混杂。两者都缺少审计后继续／降级的样本与精度门槛。 |
| 反证及竞争解释 | 优 | R1提出简单基线相当、收益依赖有利参数会削弱路线；R2还提出暴露误差主导、保守分配仅损失覆盖、日期误差不稳和根本不发生翻转，并设计替换校准与暴露的比较。R2的失败结果与核心主张联系更紧。 |
| 技术与实践价值分层 | 优（主要是表达） | R2明列既有预测／关联证据、回放决策证据、未来真实行动因果证据；R1也明确覆盖人口是情景指标、不是获救人数，备选不回答社会减损。R2层次更完整，不能据此认定实际技术收益或实践效果更大。 |
| 题名清晰度 | 弱 | R1“共享预算下，无测站洪水预警何时触发提前行动？”直指对象、约束与决策。R2题名同时包含预算分配、可靠性迁移、收益和失效边界；研究问题中的“没有本地流量标签”很关键，却没有进入题名。“可靠性迁移”对实践读者也不够直观。 |
| 无关工作量 | 相当 | 两者都避免先训练新网络、做部署或虚称减灾效果。R2增加的标签、尺度和泄漏审计与其科学问题相关，不能算无关工作；但重建流域实验、建立概率映射和地区参数核验的成本更高。若资源不足，R1的简单政策回放更容易启动；两者都应先用审计决定是否值得展开。 |

## 影响判断的设计缺口

- **R2需明确何种迁移误差能改变优先级。**同一严格单调的概率映射会保留纯概率排序；优先级翻转需要地区差异、暴露／成本权重、阈值或不确定性惩罚等具体机制。R2虽提到尺度校准与保守分配，却尚未定义这些机制及“翻转”的参照。因而问题较尖锐，但其核心可识别性尚未闭合。
- **两者都需先落实可执行预算制度与信息集。**共享资金是否可跨地区重分配、预报何时发布、预算是否补充、行动如何覆盖人口，都直接决定回放解释。R2“及时覆盖真实暴露人口”比R1情景指标措辞更强，只有独立的事后暴露记录与明确的行动覆盖规则成立时才可如此解释，仍不能推出真实减损。
- **两者都未完成最近邻排除和数据可行性验证。**没有匹配样本、真实成本及连续事件／非事件标签时，研究路径只能暂定。备选可降低外推目标，不能替代原问题已经可做的证明。

## 有限事实核查

仅对产物已引的四个公开页面作直接核查，没有另做检索或新研究。[Nearing的Zenodo档案](https://zenodo.org/records/10397664)确认日频、Google与GloFAS单位不同、时间戳右标，也明确档案包含Google再预报与GloFAS再分析；这要求任何提前行动比较区分再分析与当时可得预报。页面本身未认证原始概率、整流域留出输出或匹配样本数。

[Gupta DOI](https://doi.org/10.1016/j.rcns.2026.03.005)、[Planning ahead DOI](https://doi.org/10.1016/j.ijdrr.2026.106249)、[Kuipers DOI](https://doi.org/10.1111/jfr3.70247)在本次工具中无法读取正文。因此相关邻近性描述保持未验证；访问失败不等于文献不存在或陈述错误。两产物所述实看图和调用轨迹也未被独立复核。

R2在机制区分、数据防泄漏与反证设计上更具体；R1在题名与资源有限条件下的启动路径上更直接。此比较支持局部设计判断，不认证绝对新颖性、已完成研究结果或总体版本提升。
