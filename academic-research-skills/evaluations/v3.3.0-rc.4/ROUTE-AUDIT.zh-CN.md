# rc.4 逐字研究路线验收

验收依据是实际文件，基线为已发布rc.3，修改对象是通用Skill。按用户最新要求停止科研个案验证；本轮只做文本、结构、软件与发行验收，再发布正式版。附件与早期计划作为需求背景，最新用户要求覆盖其中继续科研试验的旧安排。当前上传文本仍可读取，最初Downloads附件路径已不存在；本轮依据已整合的rc.3源码及当前用户五项要求审查，不重新执行附件中的旧实验计划。

逐字审读19个SKILL入口、27份共用参考、19份专业协议、交接、路由、阅读层级和模板说明。阅读范围与文件摘要见[READ-COVERAGE.json](READ-COVERAGE.json)。相同文本的分发副本由构建一致性逐字节检查；不是把关键词命中当作语义验收。14条计算路线逐行检查目标、证据和实现的对应。

## 五项核心要求

| 要求 | 实际维护位置 | 验收判断 |
|---|---|---|
| topic-novelty由新颖性核查成为贡献搜索 | topic-novelty/protocol的“从核查新颖性到寻找贡献”；research-quality的研究承诺 | 按问题、能力差异和实际检验推进；题名未见过不算创新。仅选题请求保留候选交付范围。 |
| 核心贡献对应最强竞争者和决定性实验 | research-design/protocol的理论、测量与识别及方法对比 | 对应解释/方法、可观察差异及反驳条件；补核关键竞争实现，无法取得不能宣称胜过。 |
| analysis-execution成为discovery loop | analysis-execution/protocol的偏离、失败与冻结 | 区分工程错误与科学异常，形成新假设/方法/命题/设计并检验；检查数量不冒充贡献。 |
| Contribution Escalation及Manuscript Backpropagation | research-quality、manuscript-writing/review协议 | 弱贡献回到可执行研究动作；只有审稿/写作授权时提出具体补研究方案，不自行开实验。 |
| 贡献锁定后正式原创全文 | research-quality的正式全文锁定；总控与写稿入口 | 核问题、近邻、增量、真实决定性输出及范围。局部改稿、方案和注册报告不要求未来结果。 |

这些机制在通用指令中成立；文本与软件验收不证明Agent在任意领域都能自动创造贡献。正式版不保证原创发现、物理成效或录用。

## 发现并修正的穿帮与冗余

| 原文/原路线问题 | 实际修正 | 影响 |
|---|---|---|
| “最强近邻”容易被理解成全领域唯一冠军 | 共用研究质量定义最强适用竞争者；不同贡献可对应不同近邻 | 比较有明确问题、条件和证据范围。 |
| “持续到…贡献成立”“没有固定轮数”可能维持无效无限循环 | 生命周期接入路线退出条件；没有可改变判断的有限检验就停止该路线，预估下一步成本 | 保留高目标和负结果，避免诊断、复核、已知组合被反复当进展。 |
| “重新选题”“数字转化”可替换用户固定问题 | 区分开放选题与固定问题，改变总体/核心证据要求须确认 | 可自主优化已授权方法，不能偷换目标。 |
| 选题、写作回传默认执行计算 | topic-novelty与共享回传按授权范围分流 | 候选推荐、审稿、局部改稿保持局部范围；完整研究继续发现循环。 |
| journal-intelligence描述仅允许投稿匹配，正文却提供landscape | 描述同时接入标杆学习与期刊匹配；删除自动转移物理主张的入口句 | 标杆学习能正确发现；期刊匹配不擅自改研究。 |
| 旧execution-routing写“已有结果→核对后写稿” | 完整原创稿先核贡献、竞争者和决定性证据；局部改稿直接做 | 消除绕过贡献门槛的旁路。 |
| START_HERE把所有图表放到贡献锁定后 | 明确探索中可用图诊断与检验，正式原创全文仍在锁定后 | 主图和异常能反馈研究。 |
| 数据冻结要求所有下游无差别失效 | 只按实际依赖更新受影响位置 | 无关分析、图文继续复用。 |
| 分段执行指导过度贴近具体物理测试 | 泛化为任务所需状态、时间、输出语义与必要不变量/观测量 | 不强迫所有领域检查某类物理量或测试对象。 |
| 指定专业实现缺失可能卡在重复接入 | 保留核验版、如实记录未完成步骤，继续独立研究及能完成的专业工作 | 不冒充指定调用，不让全项目卡死。 |
| 辅助字段标题“rc.4”歧义；架构固定13来源过时 | 改为可选字段、按实际来源清单；同步兼容总控目录 | 版本与维护/分发说明一致。 |

## 19项能力逐项结论

| 能力/步骤 | 判断与保留/优化理由 |
|---|---|
| research-intake | 保留目标、领域、可得材料及数字路径；补固定问题的转化边界。不把资源扫描当所有任务前置。 |
| journal-intelligence | 修复入口范围；保留顶刊跨篇问题、模型、数据与尺度学习，以及终稿官方要求匹配。 |
| literature-discovery | 保留标杆学习库与直接证据库，反证不按期刊级别删。覆盖决定停止，不是无限搜索。 |
| paper-deep-reading | 保留实际摘要/正文/图表层级和跨篇迁移；只读到的内容可主张。逐项说明按任务选用。 |
| topic-novelty | 贡献搜索继续；补仅候选请求边界。成熟算法产生重要新知识仍可有贡献。 |
| research-design | 保留竞争预测、公平比较、决定性操作；删除“直到差异可观察”的无界要求，接入路线退出。 |
| ethics-protocol | 保留实际许可/审批/披露；只针对实际活动，不把模板当批准。独立合法工作继续。 |
| data-discovery | 保留字典/代表记录先匹配，再合法下载/冻结；镜像不作为独立来源。 |
| data-preparation | 保留连接、独立单位、缺失/测量与防泄漏；下游更新改为依赖范围。 |
| analysis-execution | 保留新假设—再检验循环、原始证据及负结果；泛化续算规则，环境检查按计算需要。 |
| robustness-reproducibility | 保留主张驱动的敏感性/独立复算及失败边界；不强制跑所有检验或追求显著。 |
| scientific-visualization | 保留证据任务、真实数据、编辑源与实际视觉检查；已有合适图可核查保留，不凑调用次数。 |
| manuscript-writing | 保留详细专业写作协议与贡献触发；计划/局部修改例外明确。表达缺口与科学缺口分别修复。 |
| citation-audit | 保留身份、版本、原始支持及出版状态；元数据成功不证明论断支持。 |
| manuscript-review | 保留实际科学/语义/稿件审查与具体修订；已有“仅审稿不自动研究”与共享规则现一致。 |
| submission-packaging | 保留官方要求、实际文件与作者事项；投稿包、实际提交与发表状态分开。 |
| peer-review-response | 保留真实意见→改动→证据→回复→新位置；不伪造补实验或未来意见。 |
| publication-stewardship | 保留实际校样、版本、更正及归档回执；没有真实输入不启动未来阶段。 |
| research-paper-workflow | 保留可选总控和三队列；修旧路由，同步兼容副本，19能力不是打卡顺序。 |

## 14条计算路线逐行结论

| 路线 | 原创目标与决定性证据是否衔接 | 应避免的冒称 |
|---|---|---|
| public-data | 新知识/测量及真实独立来源、识别/敏感性相接 | 下载真实数据不自动有贡献。 |
| representation-learning | 新目标/策略/结构与公平基线、消融、留出相接 | 模型组件数量不等于创新。 |
| efficient-inference | 新推理能力与精度—时间—内存及未开发任务相接 | 已知实现优化不冒充新算法。 |
| optimization | 求解/约束方法与解质、最优差距、困难实例相接 | 缩成容易实例不算正式规模。 |
| formal-theory | 命题/条件/界与证明、反例相接 | 数值线索不算证明。 |
| numerical-methods | 求解/误差/逆问题与收敛、稳定性、参考解相接 | 实现通过不证明模型适用。 |
| simulation-control | 新策略与扰动、留出任务、样本效率相接 | 仿真性能不等于实体部署。 |
| digital-design | 新结构/设计与可执行项目、约束、独立求解相接 | 计算设计不冒称物理验证。 |
| geospatial | 空间规律/重建与时空留出及尺度测量相接 | 邻近像元不自动是独立样本。 |
| bio-materials | 新模式/预测/筛选与独立结构/序列/时间划分相接 | 计算候选不等于生物有效性。 |
| networks | 传播/协调/结构与真实网络及竞争机制相接 | 可解释模拟不独自证明因果。 |
| software-systems | 新系统能力与真实负载、剖析、正确性相接 | 跑通软件不等于科学增量。 |
| digital-humanities | 新现象/解释与版本语境、材料定位、替代解读相接 | 词频不单独证明解释。 |
| evidence-synthesis | 新综合/系统误判与实际提取、纳入/依赖、划分相接 | 命中数不等于完整综合。 |

路线表保留为按需候选；未增加必跑路线或固定工具。专业库、推导片段、格式示例与可选软件自检具有通用用途，保留；具体科研试题、数据、参数、答案与结论不进入运行包。

## 内容隔离及发行门槛

源码/运行包分离规则继续：运行包排除tests、evaluations、test-results、history、previous-release、source-diffs及开发报告。本报告与阅读摘要都在evaluations，不进入运行包。对最近科研个案的名称、路径、方法名及结果数字扫描无命中，并实际审读新增通用规则；关键词扫描仅为辅助，不能单独证明绝无语义污染。兼容总控保留旧独立v2助手，当前总控资源同步自维护版。

发布rc.4前通过本库既有完整软件回归、root回归、19入口结构检查、977构建一致性及打包检查；对实际rc.4归档再检查路径、逐文件摘要、安装/恢复。正式版采用相同研究指令，只同步发行元数据与当前文档，并重新构建、核验最终包。具体检查范围见[VALIDATION.zh-CN.md](VALIDATION.zh-CN.md)和发行页收据。
