# 行为与控制验收

两层证据分开报告：控制工具功能回归检查真实进程、文件、预算增量和输入输出身份；独立Agent前向测试检查该Agent实际做了哪些有限工作。状态字段或关键词本身不证明专业流程/科学判断。

## 九类场景

| 场景 | 证据与行为 | 实际覆盖 |
|---|---|---|
| 安装完成后续接 | 维护关闭保留installation-v340，最新指令恢复，无安装调用；原输入缺科学假设时交付缺输入报告 | 功能回归 + 独立Agent选择，不声称真实科研续接成功 |
| 假设不扩成历史重建 | 软件假设据真实启动记录判断，无历史检索/数据下载 | 独立Agent局部行为；未重跑历史课题 |
| 贡献/检验不足 | 实际比较两个完全相同预测，保存障碍报告，route_closed | 有限软件数值操作，不认证现实学术原创性 |
| 依赖失败 | 两种不同真实本地检查失败，第三次repair被拒；仅2条实际尝试记录，无重装 | CLI + 实际Agent停止选择 |
| 证据足够成稿 | 用既有启动文件形成软件短稿，research→manuscript→delivery，无新研究运行 | 专业范围选择，不是科学论文完成 |
| 预算触顶 | 过期状态run退出2且无标记/日志；功能回归还测运行中截止实际停止子进程和token增量触顶 | 真实启动/停止；不保证所有宿主API采样停止 |
| 压缩后恢复 | 快照/序列化保留最新指令、完成事项、修复、deadline及计量基点；两轮仍须复评 | 模拟交接，不强制触发平台压缩 |
| 暂停 | 未来截止的paused状态仅因phase_paused拒绝run，无标记/日志；宿主目标未改 | 当前工具路径；没有把本地暂停冒充平台goal暂停 |
| 局部写作 | 独立Agent只改给定摘要，没有新状态、检索、实验或科学事实 | 实际局部编辑一次行为 |

独立报告及真实argv/退出码见forward-validation；不依赖测试答案关键词打分。原第一轮resume禁止状态退出0已修成2；第二轮发现快照遗漏unchanged_rounds，已补该字段与meter/预算细节，功能回归核对精确轮数2及相同基点。独立报告保留发现时的结果，不回写为“当时通过”。

新增功能回归还覆盖：总预算中的交付预留不重复扣短阶段时间；源码收据不能略去支持文件；init不能覆盖状态；不可靠token计量拒绝承诺上限；输入/缓存输入/输出按实际累计计数的增量分别计算；重试、换阶段、恢复不重置；来源缺失/字节改变拒绝虚报准备成功。

小型完整软件流程见integration/mini-flow-confirmed：新建可行性/设计证据，真实runner创建event.json，核值后据证写report.md，CLI完成交付，重复启动被拒。它只验证阶段与软件产物链，没有科学课题、模型训练、论文原创性或投稿。

最终完整工程回归、兼容目录回归及生成检查见test-results；旧失败记录留存，不以失败前的通过数冒充最终结果。真实使用成本有输入/缓存输入/输出计量能力，但本轮没有对整个维护任务设token上限或宣称严格token预算达标。
