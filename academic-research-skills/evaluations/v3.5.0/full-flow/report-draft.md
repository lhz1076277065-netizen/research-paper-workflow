# 汇总优势不足以说明每种工况更好：合成benchmark重算报告

本报告是流程验证草稿，不是真实科研、原创性核查或发表稿；人工科学核验未完成。

冻结问题是汇总率更高能否推出每种工况都更好。唯一原始来源E001为四行虚构benchmark日志（raw.csv）；现有汇总率可能混合不同工况比例，这是本次待判别的竞争解释。没有文献检索，最近邻研究未知，不声称存在真实领域缺口。

按运行前design.md，执行三项有限检查：数据完整性、汇总与分层成功率、相同工况权重重算。analysis.py用Python标准库Fraction精确计算；results.json为E002。全部四行保留；无训练、随机实验、显著性检验或置信区间。

A汇总率更高，但在easy和hard两层均较低，这个冻结材料中的反例否定了“汇总优势足以说明每种工况更好”的推断（C001）。A的easy权重为5/6，B为1/6；若两方法都采用共同easy权重w，则A−B=−3/20+w/10，在0≤w≤1时始终为负（C002）。因此不同混合组成足以造成本例算术排名反转；不需要新增实验才能回答原问题。

新的判断是比较结果应连同工况与权重报告。结论只涉及给定两种工况和四行合成计数；实际任务是否同质、独立性、选择机制、因果效果与未来工况表现均未知，不能推广为真实方法B普遍更好。人工核验、投稿就绪和新颖性均未评估。

证据提纲：C001的反例=E001四行及E002汇总/分层率；C002的共同权重代数=E002精确条件率和analysis.md。E001/E002只经Agent本地读取与重算，未冒充具名人类verification。报告记录正负方向并据反证收窄原主张。
