# Synthetic manuscript-completion test
The files are a small synthetic decision-cost study, not field deployment evidence. outcome=1 means an event requiring action; action=1 incurs cost c on every acted case, and misses incur loss L when outcome=1 and action=0. The supplied probability is treated as an input forecast, not a validated field probability. Each case is equally weighted. Compare total modeled cost on this fixed packet; no sampling/causal claim follows. The current method acts when probability*miss_loss > action_cost, the reported comparator acts when probability>0.5. Draft claims are provisional author text; raw inputs are authoritative.
