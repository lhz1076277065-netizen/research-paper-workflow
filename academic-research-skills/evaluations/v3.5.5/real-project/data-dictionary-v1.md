# Data dictionary and validity
Original headerless CSV: first column cultivar class 1/2/3, next 13 feature columns in official wine.names order. Alcohol = first feature; color_intensity = tenth feature. All fields parsed; 178 rows, 14 numeric columns; class counts 59/71/48; no missing/nonfinite cells, no exact duplicate complete rows. No records excluded, no imputation, no transformation, no train/test split. One observation is a recorded wine; sampling frame, instrument, batch, repeated measurements and collection dates are not documented. Unit fields are blank, so no percentage or absorbance unit is invented. No direct identifiers. Derived CSV adds verified names only and preserves numerical values. Whole-file profile limit is 1000 rows, above actual 178; raw rows sorted in class order. Preplanned Q1/Q2 remain descriptive.
