# Preserved v2 helpers

This folder exposes the current complete orchestrator at `SKILL.md`. Its scripts, references and assets from the earlier v2 workflow are retained for existing projects. The original entry is archived as `LEGACY_V2_ENTRY.md` for provenance, rather than loaded as an additional mandatory workflow.

`init_research_project.py`, `validate_research_package.py`, `research_validation/`, the old CSV templates and the nine files in `assets/profiles/` use the v2 project format. Their validator result concerns that legacy format; it is not the completion criterion for every v3 task. The current library's sixteen extensible profiles are separately stored in `assets/research-profiles.json` and documented in the current references.

Use the complete library at `../academic-research-skills/` for development, nineteen-capability discovery, current documentation and versioned release packages. This compatibility folder intentionally preserves the old helper names and inputs.
