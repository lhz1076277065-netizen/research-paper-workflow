# Academic Research Skills

Local candidate **3.4.0-rc.1**, maintained from stable v3.3.1. It adds executable bounded phases, durable recovery and fourteen pinned professional-source entrypoints. One orchestrator and eighteen standalone specialists are generated from maintained source. The candidate is delivered locally; no GitHub publication was performed.

Use the local one-click/runtime/source packages and their SHA256SUMS; do not fetch a nonexistent rc remote release.

Full research begins with bounded feasibility and one authorized subsequent budget. Maintenance ends at verified delivery, focused tasks stay focused, and completed installation is not restarted after compaction. Evidence supports conclusions; lacking a feasible decisive test leads to a blocker report rather than indefinite research or a fabricated completed paper.

Fourteen repositories retain real pinned source identities, typed entrypoints and recorded adaptations. Preparation alone does not complete a professional workflow, and each paper selects only needed implementations. Native hardware/tool limitations remain explicit. Phase control constrains only checked actions and its own process groups; it cannot guarantee host sampling stops or eliminate platform capacity/compaction failures.

The source validation archive is under academic-research-skills/evaluations/v3.4.0-rc.1, including diagnosis, behavior evidence, actual integration artifacts and a miniature complete software flow. Software checks do not certify general scientific originality or long-running agent research quality.

The root research-paper-workflow directory retains a synchronized compatibility copy plus old v2 helpers and nine legacy profiles for existing consumers. Prefer academic-research-skills/skills/research-paper-workflow for installation; do not install two copies with the same name. Historical releases and experiments remain preserved.
