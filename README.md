# Academic Research Skills v3.5.2

1个总控和18个独立专业Skill，从选题、设计、实验到图表、全文和复核，以“真实缺口 → 既有局限或竞争解释 → 本文贡献与判别证据 → 新认知及边界”贯穿研究。结论随实际证据修订，保留反证和零结果；不把故事框架当作录用保证。

本版接续v3.5.0，包含自主解阻、阶段重排和图稿回传研究：单一路线失败先诊断、比较替代、最小验证并继续；证据足够就成稿，真实总预算与用户暂停保留。常规研究登录、免费条款与token配置沿用用户授权自主办理。

资料获取前估算必要子集、累计下载与本机峰值。每个研究的累计下载和项目占用各最多200 GB，另保留10 GB磁盘余量；重试、清理和换阶段不重置累计数。只提供整包时允许整包，按需解压。受管工具实施实际限额，外部工具另设真实边界并登记计量。

每个专业步骤必调14库内匹配的真实入口，读取并实施后finish/check才移交；23个入口及支持文件固定核验，不能跳过来源自行完成再补记。方法按科学有效性、判别信息与实测成本选择。局部请求保持原范围，维护不启动具体研究。

默认核心说明按UTF-8字节减少38.40%，19入口减少11.09%，专业调用默认输出减少89.23%；完整指导和历史仍保留，按当前步骤读取。743项本地回归、30项兼容检查、19项结构校验通过，独立短流程实际自主完成鉴权、整包获取、必要成员解压及分析。验收范围见[记录](academic-research-skills/evaluations/v3.5.2/VALIDATION.zh-CN.md)，不认证长期无人科研、真实MFA或论文原创性。

运行、源码与一键安装包来自同一发布提交，包含逐文件摘要。默认安装全部19项到~/.agents/skills，替换前备份；安装后核验，再按用户要求清理旧副本。新会话读取新提示。历史[v3.5.0](https://github.com/lhz1076277065-netizen/research-paper-workflow/releases/tag/v3.5.0)、[v3.4.1](https://github.com/lhz1076277065-netizen/research-paper-workflow/releases/tag/v3.4.1)保持不变。
