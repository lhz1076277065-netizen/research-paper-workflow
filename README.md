# Academic Research Skills v3.5.6

v3.5.6修复语言、科学目标和方法变更后的旧成果误用，支持按实验范围精确失效，并减少恢复时重复校验。

完整研究固定科学问题与目标范围，允许自主调整数据、方法和题目措辞；恢复保留全部必答问题。以原问题得到有效回答、实验进入正文和全文论证连贯为交付依据。可靠零结果可以成稿，未检验或执行失败不能冒充答案。诊断可在部分数据就绪后进行，正式实验仍要求全部必要数据完整落地。保留14库必调、自主解阻及200 GB双容量限制。

自动科研总控与18个专业Skill，保留14库真实来源必调。先完成研究计划、评估并完整下载全部必要数据到本机，核验后本机实验与复算，再科研绘图、写稿审查、润色及事实核对。官方子集满足研究需要时，无需下载整个数据池。
