# Academic Research Skills v3.5.0

将“真实缺口 → 既有局限 → 本文贡献与判别证据 → 新认知及边界”落实到选题、设计、实验、图表与写作。由实际结果更新主线，保留反证；不是先定故事再挑数据。总控与18个专业能力均保留14库必调、阶段预算与恢复规则。
